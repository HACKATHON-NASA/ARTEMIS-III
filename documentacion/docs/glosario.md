# Glosario de siglas y términos

> [← Volver al inicio](../README.md)

## Medicina y fisiología

| Sigla / término | Significado |
|---|---|
| **BMD** | Densidad mineral ósea (*bone mineral density*) |
| **CMO** | Oficial médico de la tripulación (*Crew Medical Officer*); no siempre es médico |
| **CTX / NTX** | Telopéptidos C y N del colágeno tipo I: marcadores de resorción ósea |
| **DXA** | Absorciometría de rayos X de energía dual (mide la densidad ósea) |
| **ECG** | Electrocardiograma |
| **FC** | Frecuencia cardiaca, en latidos por minuto (lpm) |
| **FR** | Frecuencia respiratoria, en respiraciones por minuto (rpm) |
| **Hb / Hto** | Hemoglobina / hematocrito |
| **IOP / PIO** | Presión intraocular |
| **LBNP** | Presión negativa en la parte inferior del cuerpo (contramedida) |
| **OCT** | Tomografía de coherencia óptica (imagen de la retina) |
| **P1NP** | Propéptido N-terminal del procolágeno tipo 1: marcador de formación ósea |
| **PA** | Presión arterial |
| **PVT** | Prueba de vigilancia psicomotora (*Psychomotor Vigilance Test*): tiempo de reacción |
| **QCT** | Tomografía computarizada cuantitativa |
| **QTc** | Intervalo QT del ECG corregido por la frecuencia cardiaca |
| **RMSSD** | Raíz cuadrática media de las diferencias sucesivas entre latidos; medida de la VFC |
| **SANS** | Síndrome neuro-ocular asociado al vuelo espacial |
| **SpO₂** | Saturación de oxígeno por pulsioximetría |
| **TRT** | Grosor retiniano total (*total retinal thickness*), medido con OCT |
| **VFC** | Variabilidad de la frecuencia cardiaca |
| **VTE** | Tromboembolismo venoso |

## NASA y operaciones espaciales

| Sigla / término | Significado |
|---|---|
| **ARED** | Dispositivo avanzado de ejercicio de resistencia de la ISS |
| **BME** | Ingeniero biomédico del control de misión |
| **CHAPEA** | Análogo de exploración de salud y rendimiento de la tripulación (hábitat marciano simulado en Houston) |
| **CHeCS** | Sistema de atención de salud de la tripulación de la ISS |
| **DSN / NSN** | *Deep Space Network* / *Near Space Network*: redes de comunicaciones de la NASA |
| **DTN** | Redes tolerantes a retardos e interrupciones (*Delay/Disruption Tolerant Networking*) |
| **EVA** | Actividad extravehicular (caminata espacial) |
| **ExMC** | Capacidad médica de exploración (*Exploration Medical Capability*) |
| **GCR** | Rayos cósmicos galácticos |
| **HRP** | Programa de Investigación Humana de la NASA |
| **ISS** | Estación Espacial Internacional |
| **LEO** | Órbita terrestre baja |
| **LSAH / LSDA** | Estudio longitudinal de salud de los astronautas / archivo de datos de ciencias de la vida |
| **OCHMO** | Oficina del Jefe de Salud y Medicina de la NASA |
| **OSDR** | Repositorio de datos de ciencia abierta de la NASA |
| **RIDGE** | Las cinco amenazas del vuelo espacial: Radiación, aIslamiento, Distancia, Gravedad y Entornos hostiles |
| **SMAC** | Concentración máxima admisible en una nave (*Spacecraft Maximum Allowable Concentration*): límite de la NASA **por compuesto** del aire |
| **SPE** | Evento de partículas solares |

## Software y datos

| Sigla / término | Significado |
|---|---|
| **API REST** | Interfaz de servicios web basada en HTTP y JSON |
| **EWMA** | Media móvil ponderada exponencialmente |
| **FHIR** | Estándar HL7 de interoperabilidad de datos clínicos |
| **Idempotencia** | Propiedad de una operación que, repetida, produce el mismo resultado (no duplica datos) |
| **Inertia.js** | Capa que conecta las rutas de Laravel con páginas de Vue sin construir una API aparte |
| **Línea base** | Valores de referencia propios de cada tripulante, contra los que se compara su evolución |
| **LOINC** | Catálogo estándar de códigos para observaciones clínicas y de laboratorio |
| **MVP** | Producto mínimo viable: la versión que se presenta en el evento |
| **Offline-first** | Diseño en el que la aplicación funciona sin conexión y sincroniza después |
| **PWA** | Aplicación web progresiva: se instala desde el navegador y funciona sin conexión |
| **UCUM** | Código unificado para unidades de medida |
| **Puntuación z** | Distancia de un valor a la media de la línea base, medida en desviaciones estándar |
