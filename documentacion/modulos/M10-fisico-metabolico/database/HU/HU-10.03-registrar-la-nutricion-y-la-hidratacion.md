## Especificación

**Migración `create_registros_nutricion`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | Generado en el cliente |
| `tripulante_id` | `$table->uuid('tripulante_id');` | |
| `tipo` | `$table->string('tipo', 8);` | `comida` o `liquido` |
| `descripcion` | `$table->string('descripcion', 100)->nullable();` | |
| `kcal` | `$table->unsignedSmallInteger('kcal')->nullable();` | Solo `comida`; 0–3000 |
| `proteina_g` | `$table->unsignedSmallInteger('proteina_g')->nullable();` | Solo `comida`; 0–300 |
| `volumen_ml` | `$table->unsignedSmallInteger('volumen_ml')->nullable();` | Solo `liquido`; 1–3000 |
| `consumido_en` | `$table->dateTime('consumido_en', 3);` | |
| `origen` | `$table->string('origen', 10);` | `manual` o `simulador` |
| `anula_id` | `$table->uuid('anula_id')->nullable();` + clave foránea | |
| `created_at` | `$table->dateTime('created_at', 3);` | |

- **Índice:** `(tripulante_id, consumido_en)`.
- **`CHECK`, solo en MySQL** (en SQLite se omite; la validación principal es el *Form Request*):

```sql
ALTER TABLE registros_nutricion ADD CONSTRAINT registros_nutricion_tipo_chk CHECK (
  (tipo = 'comida'  AND volumen_ml IS NULL AND kcal IS NOT NULL) OR
  (tipo = 'liquido' AND kcal IS NULL AND proteina_g IS NULL AND volumen_ml IS NOT NULL));
```
