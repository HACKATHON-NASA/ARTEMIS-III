Trabajo de **Inertia + Vue 3 + Tailwind CSS v4** de M10: qué páginas hay, **cómo deben verse**, qué textos llevan y cómo se comportan. Lo hace **Jhon**. Las *props* vienen de las [historias de backend](../../backend/HU/README.md).

## Reglas comunes

- Se siguen la [guía visual provisional](../../../M01-identidad/frontend/HU/README.md#guía-visual-provisional) y la [estructura común de las aplicaciones](../../../M01-identidad/frontend/HU/README.md#estructura-común-de-las-cuatro-aplicaciones) de M01. Textos para el astronauta **de tú**.
- **Capturas sin conexión:** `id` con `crypto.randomUUID()` y `encolar()` de M15. Confirmación "Guardado en el dispositivo".
- **Sin metas inventadas:** la nutrición y la fuerza no tienen objetivo ni color de "bien/mal". El ejercicio sí tiene una referencia (`metaSemanal`, hoy 840 min semanales) con su fuente.
- **Textos de los equipos:** `ared` "ARED (resistencia)", `cinta` "Cinta de correr", `cicloergometro` "Cicloergómetro".
