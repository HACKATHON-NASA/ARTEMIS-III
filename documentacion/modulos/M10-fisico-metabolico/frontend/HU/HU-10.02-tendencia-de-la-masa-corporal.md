## Página `Tierra/Fisico/Show` (`/tierra/tripulantes/{codigo}/fisico`)

```
┌──────────────────────────────────────────────────────────────────────┐
│ Estado físico · T2                                                   │
│ [Masa] [Fuerza] [Ejercicio] [Ingesta] [Glucosa]                      │
│                                                                      │
│ Masa corporal semanal                     Pendiente: −0,15 kg/semana │
│  kg                                                                  │
│  70 ┼───── línea base 70,0 (previa al vuelo)                         │
│ 66,5┼ ─ ─ ─ −5 % (umbral de aviso)                                   │
│      ● ● ● ●                                                         │
│      S1 S2 S3 S4                                                     │
└──────────────────────────────────────────────────────────────────────┘
```

| Pestaña | Contenido |
|---|---|
| Masa | Puntos por semana, línea base, línea discontinua del −`umbralMasaPct` % (umbral de `MASA_PERDIDA`, hoy 5) y pendiente en kg/semana ("—" con menos de 3 semanas) |
| Fuerza | Dos líneas (izquierda y derecha) y el cambio % frente a la primera medición |
| Ejercicio | Barras de minutos por semana con la línea de `metaSemanal` (hoy 840) |
| Ingesta | Barras de kcal y líquidos por día (14 días), sin meta |
| Glucosa | De HU-10.05 |

## Criterios de aceptación

- **Dado** una línea base de 70 kg, **cuando** se muestra la masa, **entonces** hay una línea en 70,0 y otra discontinua en 66,5.
- **Dado** `pendienteMasa = null`, **cuando** se muestra, **entonces** dice "Pendiente: —".
