| Elemento | Especificación |
|---|---|

| Selector de dispositivo | Muestra "identificador (tipo · tripulante o módulo)". No incluye los de tipo `tableta`. Si el dispositivo ya tiene token, la opción añade "· ya tiene token" |
| "Emitir token" | Si el dispositivo ya tiene token, primero abre el diálogo "¿Reemplazar el token de <identificador>?" con el texto "El token actual dejará de funcionar. El dispositivo no podrá enviar datos hasta que configure el nuevo." y los botones "Cancelar" · "Reemplazar". Al confirmar se envía `reemplazar: true` |
| Caja del token nuevo (`TokenUnaVez.vue`) | Aparece solo si llega la *prop* `tokenNuevo`. Texto en fuente monoespaciada, seleccionable y en una sola línea con desplazamiento interno. Botón "Copiar" (`navigator.clipboard.writeText`); al copiar cambia 2 s a "Copiado ✓" y se anuncia con `aria-live`. Si el portapapeles falla: "No se pudo copiar. Seleccione el texto y cópielo a mano." El botón "Ya lo copié" la oculta |
| Al salir de la página | Si la caja sigue visible, el navegador pide confirmación (`beforeunload`) |
| Tabla | Tipo en texto: "Dispositivo", "App (PWA)" o "Nodo". "Caduca": "No caduca" o la fecha. "Último uso": relativo ("hace 3 min") o "Nunca". En móvil, tarjetas |
| "Revocar" | Diálogo "¿Revocar <nombre>?" con el texto "El dispositivo o la persona que lo usa dejará de poder enviar datos." y los botones "Cancelar" · "Revocar" (destructivo). | Sin tokens | `EstadoVacio`: "Todavía no hay tokens. Emita el primero para un dispositivo." |

## Criterios de aceptación

- **Dado** que emito un token, **cuando** se carga la página, **entonces** veo la caja con el token y el aviso; **y al** recargar, la caja ya no aparece.
- **Dado** la caja visible, **cuando** pulso "Copiar", **entonces** el token queda en el portapapeles y el botón dice "Copiado ✓" durante 2 s.
- **Dado** un dispositivo con token, **cuando** pulso "Emitir token", **entonces** aparece el diálogo de reemplazo antes de enviar nada.
- **Dado** el ingeniero biomédico, **cuando** ve un token de nodo, **entonces** no aparece "Revocar"; **y el** admin sí lo ve.
- **Dado** el selector de dispositivos, **cuando** lo abro, **entonces** no aparece ninguna tableta.
