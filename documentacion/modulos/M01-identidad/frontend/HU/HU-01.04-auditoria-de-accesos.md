```

│ Auditoría ◀  │  Quién [texto         ]  Desde [2026-11-01]  Hasta [2026-11-03]       │
│              │                                                     [Quitar filtros] │
│              │                                                                       │
│              │  Fecha (UTC)        Quién                 Acción    Recurso       Tripulante  Nodo   IP          │
│              │  ───────────────────────────────────────────────────────────────────────────────────────────── │

└──────────────┴───────────────────────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Etiqueta "Solo lectura" | Junto al título; no hay ningún botón de edición |
| Filtros | Se aplican al cambiar (texto: 300 ms después de dejar de escribir) y viajan en la URL (`router.get(..., { preserveState: true, replace: true })`). "Quitar filtros" solo aparece si hay alguno activo |
| Acción en texto | `login` "Inicio de sesión", `login_fallido` "Inicio fallido", `logout` "Cierre de sesión", `ver` "Ver", `crear` "Crear", `anular` "Anular", `modificar` "Modificar", `exportar` "Exportar" |
| *Layout* | El del rol: `AdminLayout` para el admin y `TierraLayout` para el médico de vuelo |
| Filtro "Tripulante" | Opciones de la *prop* `tripulantes` |
| IP | "—" si es `null` (consola o cola) |
| Detalle | Si la entrada trae `detalle` (cambios de configuración de M16), la fila ofrece "Ver detalle": motivo y valores antes → después |
| "Quién" | El campo `actor` de la *prop*. Si es muy largo, se recorta con "…" y el texto completo va en `title` |
| "Inicio fallido" | Icono ⚠ + texto, para distinguirlo sin depender del color |
| Fecha | Con segundos (`D12 · 14:05:07`), porque la auditoría necesita precisión |
| Validación de fechas | Si "Desde" es posterior a "Hasta", el error aparece bajo "Hasta": "La fecha final debe ser igual o posterior a la inicial." y no se envía la consulta |
| Móvil | Tarjetas: fecha y acción arriba; quién, recurso, tripulante, nodo e IP debajo |
| Sin resultados | `EstadoVacio`: "No hay entradas con estos filtros." |

## Criterios de aceptación

- **Dado** el admin, **cuando** filtra por acción "Inicio fallido", **entonces** la URL contiene `accion=login_fallido` y solo ve esas filas.
- **Dado** que pongo "Desde" posterior a "Hasta", **cuando** cambio el filtro, **entonces** veo el error y no se envía ninguna petición.
- **Dado** el médico de vuelo, **cuando** abre su menú en el nodo `tierra`, **entonces** ve la entrada "Auditoría".
- **Dado** una tabla con filas, **cuando** un lector de pantalla la recorre, **entonces** cada columna tiene su encabezado `<th scope="col">`.
