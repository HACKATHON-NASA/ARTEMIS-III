| Elemento | Especificación |
|---|---|
| Botón "Nuevo usuario" | Arriba a la derecha; abre el panel de alta |
| Filtros | Búsqueda de texto (se aplica 300 ms después de dejar de escribir), "Rol" y "Estado" (Todos, Activos, Inactivos). Viajan en la URL con `router.get(..., { preserveState: true, replace: true })` |
| Columna "Rol" | Texto de la tabla de roles, nunca el valor interno |
| Columna "Estado" | Icono + texto: "Activo" o "Inactivo". Las filas inactivas se ven atenuadas, pero conservan el contraste AA |
| Columna "Tripulante" | El código (`T1`). Para `astronauta` o `cmo` sin tripulante: icono ⚠ + "Sin vincular". Para otros roles: "—". **En el Sprint 0 (sin M02) la columna no se muestra** |
| Menú de fila [⋯] | "Editar", "Cambiar contraseña", "Desactivar" o "Activar". La fila del propio admin no muestra "Desactivar" |
| Móvil | Cada usuario es una tarjeta: nombre, correo, rol, estado y tripulante, con el menú [⋯] |
| Lista vacía (con filtros) | `EstadoVacio`: "Ningún usuario coincide con los filtros." y el botón "Quitar filtros" |

- En la edición no aparecen los campos de contraseña. El botón dice "Guardar cambios".
- El selector "Rol" ofrece los 6 roles (nunca `sistema`). Si se edita al propio admin, el selector está deshabilitado y debajo se lee "No puede cambiar su propio rol.".
- Los errores `422` aparecen bajo cada campo (`useForm`). Al guardar, el panel se cierra y se muestra el aviso del *flash* `exito` ("Usuario creado." o "Cambios guardados.").

**Diálogos de confirmación**

| Acción | Título | Texto | Botones |
|---|---|---|---|
| Desactivar | "¿Desactivar a <nombre>?" | "No podrá iniciar sesión, se revocarán sus tokens y su sesión abierta se cerrará." | "Cancelar" · "Desactivar" (estilo destructivo) |
| Cambiar el rol de un usuario existente | "¿Cambiar el rol de <nombre>?" | "Pasará de <rol actual> a <rol nuevo>. Se revocarán sus tokens y verá otro menú en su próxima visita." | "Cancelar" · "Cambiar rol" |
| Cambiar contraseña | "Nueva contraseña temporal para <nombre>" | Formulario con "Contraseña temporal" y "Repetir contraseña" | "Cancelar" · "Guardar contraseña" |

Los diálogos atrapan el foco, se cierran con Esc y devuelven el foco al botón que los abrió.

## Criterios de aceptación

- **Dado** el admin, **cuando** crea un usuario con datos válidos, **entonces** el panel se cierra, aparece "Usuario creado." y el usuario está en la lista.
- **Dado** un correo repetido, **cuando** intento crear el usuario, **entonces** el error aparece bajo "Correo electrónico" y el panel sigue abierto con los datos escritos.
- **Dado** que pulso "Desactivar", **cuando** aparece el diálogo y pulso "Cancelar", **entonces** no se envía ninguna petición.
- **Dado** mi propia fila, **cuando** abro su menú, **entonces** no aparece "Desactivar"; **y en** la edición, el rol está deshabilitado.
- **Dado** el Sprint 1 (con M02), **cuando** un astronauta no tiene tripulante, **entonces** su fila muestra ⚠ y "Sin vincular".
- **Dado** que filtro por rol "Astronauta" y recargo la página, **cuando** se carga, **entonces** el filtro sigue aplicado (está en la URL).
