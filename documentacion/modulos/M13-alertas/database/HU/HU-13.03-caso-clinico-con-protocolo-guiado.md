## Especificación

**Orden:** `create_protocolos` → `create_casos_clinicos` → `add_caso_fk_to_alertas` → `create_acciones`.

**Migración `create_protocolos`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `codigo` | `$table->string('codigo', 30)->primary();` | |
| `nombre` | `$table->string('nombre', 100);` | |
| `familias` | `$table->json('familias');` | Familias que lo activan; `generico` lleva `[]` |
| `pasos` | `$table->json('pasos');` | `[{ "numero": 1, "texto": "…", "fuente": "…" | null }]` |
| `validado_por` | `$table->string('validado_por', 100)->nullable();` | Nombre y profesión |
| `validado_en` | `$table->date('validado_en')->nullable();` | `NULL` = pendiente de validación clínica |
| `created_at`, `updated_at` | `$table->datetimes(3);` | |

**Migración `create_casos_clinicos`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | |
| `tripulante_id` | `$table->uuid('tripulante_id')->nullable();` | |
| `protocolo_codigo` | `$table->string('protocolo_codigo', 30);` + clave foránea a `protocolos.codigo` | |
| `protocolo_pasos` | `$table->json('protocolo_pasos');` | **Nueva. Copia** de los pasos al abrir el caso. Si el admin edita el protocolo con el caso abierto, los `paso_numero` de las acciones siguen apuntando a los pasos que vio el CMO |
| `protocolo_validado_en` | `$table->date('protocolo_validado_en')->nullable();` | **Nueva.** Copia del estado de validación al abrir |
| `estado` | `$table->string('estado', 8);` | `abierto` o `cerrado` |
| `abierto_por` | `$table->unsignedBigInteger('abierto_por')->nullable();` | `NULL` = automático |
| `abierto_en` | `$table->dateTime('abierto_en', 3);` | |
| `cerrado_en` | `$table->dateTime('cerrado_en', 3)->nullable();` | |
| `resultado` | `$table->text('resultado')->nullable();` | Obligatorio al cerrar |
| `actualizado_en` | `$table->dateTime('actualizado_en', 3);` | |

**Migración `add_caso_fk_to_alertas`:** `$table->foreign('caso_clinico_id')->references('id')->on('casos_clinicos');`
