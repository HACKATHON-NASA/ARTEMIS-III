**Migración nueva `create_alerta_hallazgos`.** Relaciona cada hallazgo (y cada ocurrencia) con su alerta. Sin ella no se puede saber si un hallazgo pertenece a una alerta **descartada** (y no debe volver a avisar), ni evitar contar dos veces un evento que la cola reintenta:

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->id();` | |
| `alerta_id` | `$table->foreignUuid('alerta_id')->constrained('alertas');` | |
| `hallazgo_id` | `$table->uuid('hallazgo_id');` | De M12 (lógica) |
| `ocurrencia` | `$table->unsignedSmallInteger('ocurrencia');` | La del evento |
| `nivel` | `$table->string('nivel', 8);` | |
| `recibido_en` | `$table->dateTime('recibido_en', 3);` | |

- **Única:** `(hallazgo_id, ocurrencia)`: un evento repetido no se cuenta dos veces. **Índice:** `(hallazgo_id)`.
