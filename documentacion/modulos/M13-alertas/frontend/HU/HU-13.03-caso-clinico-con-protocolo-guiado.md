## Página `Cmo/Casos/Show` (`/cmo/casos/{id}`)

```
┌──────────────────────────────────────────────────────────────────────┐
│ Caso · T3 · Hipoxemia · Abierto hace 6 min                           │
│ ⚠️ Protocolo de demostración: pendiente de validación clínica        │  ← AvisoNoValidado
│                                                                      │
│ Protocolo                                                            │
│ ☑ 1. Verificar la colocación del oxímetro y repetir la medición      │
│      Fuente: NASA-STD-3001 Vol. 2 §… · hecho 10:12 por cmo@…         │
│ ☐ 2. Registrar síntomas (disnea, confusión)          [Marcar hecho]  │
│      Fuente: …                                                       │
│                                                                      │
│ Acciones                                                             │
│ 10:12 Paso 1 hecho · cmo@astrohealth.test                            │
│ 10:15 Nota: "Saturación recuperada tras recolocar" ↻ por enviar      │
│ 10:20 Recomendación · Médico de vuelo (Tierra): medico@…             │
│ [+ Añadir nota]                                                      │
│                                                                      │
│ [Cerrar caso]                                                        │
└──────────────────────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Pasos | De la **copia** del caso. Cada uno con su texto, su fuente en texto pequeño (o "Sin fuente" antes de HU-13.04) y "Marcar hecho" |
| Enlaces en los pasos | la sintaxis de enlace de Markdown (`[texto]` seguido de `(ruta)`) se muestra como enlace (p. ej., "Revisar el ECG de la ventana" en `arritmia`) |
| "Marcar hecho" y notas | Generan una acción con `id` y la **encolan** (`/api/v1/alertas/casos/{caso}/acciones`): funcionan sin conexión. Las pendientes llevan ↻ "por enviar" |
| Recomendaciones | Acciones de tipo `recomendacion` con su autor de la Tierra, destacadas con un icono |
| Cerrar caso | Diálogo con "Resultado" obligatorio (≤ 2000) y el aviso "Se cerrarán también sus N alertas." |

## Criterios de aceptación

- **Dado** un caso con protocolo sin validar, **cuando** se abre, **entonces** aparece "⚠️ Protocolo de demostración: pendiente de validación clínica".
- **Dado** que marco el paso 2 sin conexión, **cuando** miro las acciones, **entonces** aparece con ↻ "por enviar" y el paso queda marcado.
- **Dado** el caso de E1, **cuando** lo abro, **entonces** el paso del ECG es un enlace a la ventana.
