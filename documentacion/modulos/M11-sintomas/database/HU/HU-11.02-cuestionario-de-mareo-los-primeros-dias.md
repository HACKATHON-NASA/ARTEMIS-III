## Especificación

**Migración `create_respuestas_mareo`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | Generado en el cliente |
| `tripulante_id` | `$table->uuid('tripulante_id');` | |
| `dia_mision` | `$table->unsignedTinyInteger('dia_mision');` | 1, 2 o 3; lo calcula el servidor con `respondida_en` |
| `nausea`, `vomito`, `mareo`, `cefalea`, `malestar` | `$table->unsignedTinyInteger(...);` | 0–10 cada uno |
| `total` | `$table->unsignedTinyInteger('total');` | Suma (0–50), calculada en el servidor |
| `origen` | `$table->string('origen', 10);` | **Nueva.** `manual` o `simulador` |
| `respondida_en` | `$table->dateTime('respondida_en', 3);` | |
| `created_at` | `$table->dateTime('created_at', 3);` | **Nueva** |

- **Única:** `(tripulante_id, dia_mision)`: un cuestionario por día.
- Es una **estructura propia** con la forma de los cuestionarios de mareo, no un instrumento validado (lo elegirían profesionales).
