## Especificación

**Migración `create_paquetes_sync`** (cola de **salida**, en los dos nodos)

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | **Determinista** cuando el paquete representa un dato concreto (ver backend): encolar dos veces lo mismo no lo duplica |
| `tipo` | `$table->string('tipo', 20);` | `alerta`, `ajuste_umbral`, `registros`, `resumen`, `detalle`, `adjunto`, `auditoria`, `mision`, `recomendacion`, `configuracion` |
| `prioridad` | `$table->unsignedTinyInteger('prioridad');` | 1, 2 o 3 |
| `payload` | `$table->longText('payload');` | JSON; en `detalle`, JSON comprimido con gzip y codificado en base64 |
| `comprimido` | `$table->boolean('comprimido')->default(false);` | **Nueva** |
| `bytes` | `$table->unsignedInteger('bytes');` | Tamaño del `payload` tal como viaja |
| `estado` | `$table->string('estado', 10);` | `pendiente`, `enviado` (en tránsito, solo en la nave) o `entregado` |
| `creado_en` | `$table->dateTime('creado_en', 3);` | |
| `enviado_en`, `entrega_programada_en`, `entregado_en` | `$table->dateTime(..., 3)->nullable();` | |
| `intentos` | `$table->unsignedSmallInteger('intentos')->default(0);` | |

- **Índices:** `(estado, prioridad, creado_en)` y `(estado, entrega_programada_en)`.

**Migración nueva `create_detalle_empaquetado`** (solo se usa en la nave). Recuerda qué lotes de M03 ya viajan en un paquete `detalle`. Hace falta una tabla propia porque `lotes_ingesta` es de solo inserción y no se puede marcar:

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `lote_id` | `$table->uuid('lote_id')->primary();` | Lote de M03 |
| `paquete_id` | `$table->uuid('paquete_id');` | |
| `empaquetado_en` | `$table->dateTime('empaquetado_en', 3);` | |

- **Índice:** `(paquete_id)`.
