## Especificación

**Migración `create_respuestas_escala`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | Generado en el cliente, una fila por escala |
| `tripulante_id` | `$table->uuid('tripulante_id');` | |
| `escala` | `$table->string('escala', 15);` | `animo`, `estres`, `fatiga` (diarias, 0–10) · `carga_trabajo`, `cohesion` (semanales, 1–5) |
| `valor` | `$table->unsignedTinyInteger('valor');` | |
| `origen` | `$table->string('origen', 10);` | **Nueva.** `app` o `simulador` |
| `respondida_en` | `$table->dateTime('respondida_en', 3);` | |
| `created_at` | `$table->dateTime('created_at', 3);` | |

- **Índice:** `(tripulante_id, escala, respondida_en)`.
- Orientación: `animo` 0 = muy mal y 10 = muy bien; `estres` y `fatiga` 0 = nada y 10 = máximo; `carga_trabajo` 1 = muy baja y 5 = muy alta; `cohesion` 1 = muy mala y 5 = muy buena.

## Criterios de aceptación

- **Dado** las 3 escalas diarias enviadas juntas, **cuando** se guardan, **entonces** hay 3 filas con sus `id`.
