## Especificación

**Migración `create_programacion_tests`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | |
| `tripulante_id` | `$table->uuid('tripulante_id');` | |
| `tipo` | `$table->string('tipo', 17);` | `pvt`, `aritmetica`, `memoria`, `escalas_diarias`, `escalas_semanales` (`escalas_semanales` tiene 17 caracteres; la ficha anterior decía `varchar(15)`, que la cortaba) |
| `hora_utc` | `$table->time('hora_utc');` | |
| `dia_semana` | `$table->unsignedTinyInteger('dia_semana')->nullable();` | ISO: 1 = lunes … 7 = domingo. Solo `escalas_semanales` |
| `activa` | `$table->boolean('activa')->default(true);` | |
| `created_at`, `updated_at` | `$table->datetimes(3);` | Es configuración, no medición |

- **Índice:** `(tripulante_id, activa)`. **Única:** `(tripulante_id, tipo)`.

**Seeder `ProgramacionDemoSeeder`** (en los dos nodos, después de `MisionDemoSeeder`; `updateOrCreate` por `(tripulante_id, tipo)`): para cada tripulante de la misión activa, `pvt`, `aritmetica`, `memoria` y `escalas_diarias` a las 08:00 UTC, y `escalas_semanales` los lunes (`dia_semana = 1`) a las 08:00 UTC. Es la agenda del simulador.

## Criterios de aceptación

- **Dado** `migrate:fresh --seed`, **cuando** consulto `programacion_tests`, **entonces** hay 20 filas (5 por tripulante) y la de `escalas_semanales` guarda el tipo completo.
