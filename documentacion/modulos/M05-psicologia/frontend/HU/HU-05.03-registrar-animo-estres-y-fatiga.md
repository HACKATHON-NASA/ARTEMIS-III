## Página `Astronauta/Escalas/Create` (`/astronauta/como-me-siento`)

```
┌──────────────────────────────────────────────────────┐
│ ¿Cómo te sientes hoy?                                │
│ 🔒 Solo lo ven tú y el médico de vuelo.              │
│                                                      │
│ Ánimo        Muy mal  ○───────●──○  Muy bien     7   │
│ Estrés       Nada     ○──●────────○  Máximo      3   │
│ Fatiga       Nada     ○───●───────○  Máxima      4   │
│                                                      │
│ ── Esta semana ──                                    │
│ Carga de trabajo   (1) (2) (3) (•4) (5)              │
│                    Muy baja … Muy alta               │
│ Cohesión del equipo (1) (2) (3) (4) (•5)             │
│                    Muy mala … Muy buena              │
│                                                      │
│                                     [Guardar]        │
└──────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Aviso de confidencialidad | Siempre visible arriba, con icono 🔒: "Solo lo ven tú y el médico de vuelo." |
| Diarias (`DeslizadorEscala.vue`) | Deslizador 0–10 con etiquetas en los extremos y el número visible. **Empieza sin valor** (no en 5), para no sesgar la respuesta: hay que tocarlo |
| Semanales | Solo si `semanalPendiente` (faltan en la semana actual; el título dice "Esta semana", no "los lunes"). Botones de opción 1–5 con las etiquetas de los extremos |
| Guardar | Habilitado cuando las diarias (y las semanales, si se muestran) tienen valor. Cada escala lleva su `id`; se encola en `/api/v1/psicologia/escalas` y confirma "Guardado en el dispositivo" |

## Accesibilidad

- El deslizador es un `<input type="range">` con `aria-valuetext` ("7 de 10, bastante bien") y se maneja con las flechas.

## Criterios de aceptación

- **Dado** que abro la página, **cuando** la miro, **entonces** ningún deslizador tiene valor y "Guardar" está deshabilitado.
- **Dado** que respondo las tres en el teclado, **cuando** guardo, **entonces** se encola un envío con 3 respuestas.
- **Dado** `semanalPendiente = false`, **cuando** abro la página, **entonces** no aparece la sección semanal.
