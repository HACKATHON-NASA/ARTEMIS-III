## Página `Astronauta/Tests/Index` (`/astronauta/tests`)

```
┌──────────────────────────────────────────────────────┐
│ Mis tests de hoy · D12                               │
│                                                      │
│ ✓ PVT (atención)         08:00 UTC      Hecho        │
│ ⚠ Aritmética             08:00 UTC      Atrasado  [Hacer] │
│ ○ Memoria                08:00 UTC      Pendiente [Hacer] │
│ ○ ¿Cómo te sientes?      08:00 UTC      Pendiente [Hacer] │
│ ○ Escalas de la semana   lunes          Pendiente [Hacer] │
│ ↻ Aritmética             guardado sin conexión, por enviar │
└──────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Estados | ✓ "Hecho", ⚠ "Atrasado" (más de `atrasoMin` minutos tarde; hoy 60), ○ "Pendiente". Icono + texto |
| Sin conexión | Calcula el estado con `programacion` y la cola: un test de hoy en `cola_envios` cuenta como hecho con la marca ↻ "guardado sin conexión, por enviar" |
| Contador en el menú | La entrada "Mis tests" del menú de F1 muestra el número de pendientes y atrasados ("Mis tests · 3") |
| Sin notificaciones del sistema operativo | El recordatorio es esta lista y el contador |

## Criterios de aceptación

- **Dado** el PVT hecho y la aritmética atrasada, **cuando** abro la página, **entonces** se ven "Hecho" y "Atrasado" con su icono.
- **Dado** que hice la aritmética sin conexión, **cuando** abro la página sin red, **entonces** aparece como "guardado sin conexión, por enviar".
- **Dado** 3 pendientes, **cuando** miro el menú, **entonces** dice "Mis tests · 3".
