## Página `Astronauta/Tests/Aritmetica`

```
┌──────────────────────────────────────┐
│ Aritmética                   7 / 20  │
│                                      │
│              47 + 28                 │
│                                      │
│            [   75    ]               │
│                                      │
│   [1] [2] [3]                        │
│   [4] [5] [6]                        │
│   [7] [8] [9]                        │
│   [⌫] [0] [Aceptar]                  │
└──────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Motor (`MotorAritmetica.ts`) | Genera 20 operaciones de suma o resta con dos números de 10 a 99 y resultado ≥ 0 |
| Un ítem a la vez | `tiempo_ms` va desde que aparece la operación hasta "Aceptar". Sin límite de tiempo por ítem |
| Teclado | Teclado numérico propio (botones de 44 px como mínimo) y también el teclado físico (números, Retroceso, Intro) |
| Sin respuesta vacía | "Aceptar" está deshabilitado con el campo vacío |
| Sin corrección | No se dice si la respuesta es correcta |
| Fin y salida | Como en el PVT: "Hecho" al terminar los 20 ítems; "Salir" guarda la sesión incompleta |

## Criterios de aceptación

- **Dado** 1.000 operaciones generadas, **cuando** se revisan, **entonces** todas tienen dos números de dos cifras y resultado ≥ 0 (Vitest).
- **Dado** el ítem 7, **cuando** escribo 75 y pulso Intro, **entonces** pasa al ítem 8 y se guarda su tiempo.
- **Dado** el campo vacío, **cuando** pulso "Aceptar", **entonces** no pasa nada.

## Tareas

- [ ] `MotorAritmetica.ts` (puro) y la página con su teclado.
- [ ] Pruebas Vitest: generación de operaciones y avance por ítems.
