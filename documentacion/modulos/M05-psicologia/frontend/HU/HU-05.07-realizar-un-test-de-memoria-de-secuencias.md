## Página `Astronauta/Tests/Memoria`

```
Presentación (un dígito cada vez)        Respuesta
┌──────────────────────────────┐         ┌──────────────────────────────┐
│ Memoria · secuencia de 5     │         │ Escribe la secuencia         │
│                              │         │                              │
│             8                │         │       [ 5 8 2 9 _ ]          │
│                              │         │                              │
│      ●●●○○  (dígito 3 de 5)  │         │   [1][2][3] [4][5][6]        │
└──────────────────────────────┘         │   [7][8][9] [⌫][0][Aceptar]  │
                                         └──────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Motor (`MotorMemoria.ts`) | Empieza en `longitudInicial` (3). Secuencias sin dígitos iguales seguidos. Un acierto sube un dígito; **dos errores seguidos en la misma longitud** terminan; acertar en `longitudTope` (12) también termina |
| Presentación | Cada dígito durante `msPorElemento` (1.000 ms) y 250 ms en blanco entre dígitos. Indicador de progreso con puntos y el texto "dígito 3 de 5" |
| Respuesta | Teclado como en aritmética. El campo tiene tantas casillas como la secuencia; "Aceptar" se habilita al completarla |
| Entre secuencias | 1 s de pausa con "Siguiente secuencia" (sin decir si acertó) |
| Fin y salida | Como en el PVT |

## Criterios de aceptación

- **Dado** 1.000 secuencias generadas, **cuando** se revisan, **entonces** ninguna tiene dos dígitos iguales seguidos (Vitest).
- **Dado** dos errores en la longitud 7, **cuando** se registran, **entonces** el test termina.
- **Dado** un error en 7 y después un acierto en 7, **cuando** se registra, **entonces** sigue con 8.
- **Dado** la secuencia de 5, **cuando** se presenta, **entonces** cada dígito dura 1.000 ms con 250 ms en blanco entre ellos.
