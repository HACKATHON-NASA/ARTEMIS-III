## Página `Admin/Exportaciones/Index` (`/admin/exportaciones`, reemplaza la temporal de M01)

```
┌──────────────────────────────────────────────────────────────────────┐
│ Exportación anonimizada                                              │
│                                                                      │
│ Días de misión  desde [ 10 ]  hasta [ 16 ]   (máximo 7 días)         │
│ Variables       [☑ Frecuencia cardiaca] [☑ SpO₂] [☐ Temperatura] …   │
│ ☐ Incluir sexo y grupo de edad                                       │
│   ⚠ Con 4 tripulantes, estas dos columnas casi identifican a cada    │
│     persona. Inclúyelas solo si son imprescindibles.                 │
│                                          [Exportar CSV]              │
│                                                                      │
│ Mis exportaciones                                                    │
│ D10–D16 · FC, SpO₂   ↻ Generando…                                    │
│ D1–D7   · FC         ✓ Lista     [Descargar CSV (4,2 MB)]            │
│ D3–D5   · Temp.      ✖ Error: Falta SEUDONIMO_KEY                    │
└──────────────────────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Rango | Dos campos numéricos con los límites de `diasMision`. Más de `maxDias` (hoy 7) días: "Elige como máximo 7 días por exportación." y el botón deshabilitado |
| Sexo y edad | **Desmarcado por defecto**, con el aviso de reidentificación siempre visible debajo |
| Estado | ↻ "Generando…" (se refresca con `usePoll(5000, { only: ['exportaciones'] })` mientras haya alguna pendiente), ✓ "Lista" con la descarga, ✖ "Error" con el mensaje |
| Nota fija | "Los datos están seudonimizados, no anonimizados del todo: no los compartas fuera del equipo de investigación." |

## Criterios de aceptación

- **Dado** un rango de 8 días, **cuando** lo escribo, **entonces** veo el error y "Exportar CSV" está deshabilitado.
- **Dado** una exportación pendiente, **cuando** pasa a lista, **entonces** aparece "Descargar CSV" sin recargar la página.
- **Dado** que abro la página, **cuando** la miro, **entonces** "Incluir sexo y grupo de edad" está desmarcado.
