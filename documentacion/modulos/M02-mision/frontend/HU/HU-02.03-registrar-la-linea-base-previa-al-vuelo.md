## Página `Tierra/LineaBase/Edit` (`/tierra/tripulantes/{codigo}/linea-base`)

```
┌──────────────────┬───────────────────────────────────────────────────────────────────────┐
│ Centro médico    │  Línea base previa al vuelo                                           │
│ Línea base ◀     │  Tripulante: [ T1 ] [ T2 ] [ T3 ] [ T4 ]        ↻ Pendiente de llegar │
│ Auditoría        │                                                      a la nave        │
│                  │  T2 · Laura Méndez                                                    │
│                  │                                                                       │
│                  │  Variable                   Vigente            Media     Desv. (σ)  Mediciones │
│                  │  ────────────────────────────────────────────────────────────────────────── │
│                  │  Frecuencia cardiaca (lpm)  61 ± 3             [      ]  [      ]   [    ]     │
│                  │                             Previa al vuelo · D12                           │
│                  │  SpO₂ (%)                   —                  [      ]  [      ]   [    ]     │
│                  │  Frecuencia respiratoria    —                  [      ]  [      ]   [    ]     │
│                  │  …                                                                     │
│                  │  Masa corporal (kg)         —                  [      ]  [      ]   [    ]     │
│                  │                                                                       │
│                  │  Solo se guardan las filas completas.         [Guardar línea base]    │
└──────────────────┴───────────────────────────────────────────────────────────────────────┘
```

**Props**

```ts
{
  tripulante: { id: string, codigo: string, nombre: string },
  tripulantes: { codigo: string }[],                   // para el selector
  variables: { codigo: string, nombre: string, unidad: string, contexto: 'reposo' | null,
               min: number, max: number }[],          // las 8 de VariablePrevuelo, en su orden
  vigentes: { codigo: string, contexto: string | null, media: number, desviacion: number, n: number,
              fuente: 'previa_vuelo' | 'ventana_inicial' | 'recalculo_autorizado', created_at: string }[],
  sincronizada: boolean | null                         // null hasta HU-15.01: no se muestra nada
}
```

| Elemento | Especificación |
|---|---|
| Selector de tripulante | Botones (uno por código) con `aria-current` en el actual; cada uno navega a su URL |
| Columna "Vigente" | "61 ± 3", y debajo en pequeño la fuente ("Previa al vuelo", "Días 1–7 de misión" o "Recálculo autorizado") y el día en que se registró, con `DiaMision` corto ("D12" o "Previo al vuelo"). Sin línea base: "—" |
| Campos | `inputmode="decimal"`; admiten coma decimal ("61,5") y se convierten a punto antes de enviar. "Mediciones" es entero |
| Fila a medias | Si una fila tiene uno o dos de los tres campos, se marca en el navegador con "Complete media, desviación y mediciones, o deje la fila vacía." y no se envía nada |
| Envío | Solo las filas completas, como `valores: [{ codigo, media, desviacion, n }]`. Los errores del servidor (`valores.3.media`…) se muestran bajo el campo de esa fila |
| Sustitución | Si alguna fila completa ya tiene una línea base vigente, antes de enviar aparece el diálogo "¿Sustituir la línea base vigente?" con el texto "Las líneas base nuevas pasarán a ser las de referencia. Las anteriores se conservan en el historial." y los botones "Cancelar" · "Sustituir" |
| Estado del envío a la nave | `sincronizada = false`: icono ↻ + "Pendiente de llegar a la nave". `true`: ✓ "En la nave". `null`: no se muestra |
| Éxito | El mensaje del servidor ("Línea base guardada (N variables).") y los campos vacíos de nuevo |

## Criterios de aceptación

- **Dado** T2 con FC vigente 61 ± 3, **cuando** abro su página, **entonces** la fila de FC muestra "61 ± 3" en "Vigente".
- **Dado** que escribo "68,5" en la media de la masa corporal, **cuando** se envía, **entonces** el cuerpo lleva `68.5`.
- **Dado** una fila con media pero sin desviación, **cuando** pulso "Guardar línea base", **entonces** veo el aviso de esa fila y no se envía nada.
- **Dado** que relleno la FC de T2, que ya tiene una vigente, **cuando** pulso "Guardar línea base", **entonces** aparece el diálogo de sustitución antes de enviar.
- **Dado** `sincronizada = null`, **cuando** se muestra la página, **entonces** no aparece ningún estado de envío.
- **Dado** el teclado, **cuando** recorro la tabla con Tab, **entonces** paso por media, desviación y mediciones de cada fila, en orden.
