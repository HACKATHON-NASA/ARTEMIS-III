## Especificación

**Migración `create_hallazgos`.** Amplía la de la ficha con las columnas que necesita el **episodio**: el motor actualiza un hallazgo abierto mientras la condición sigue cumpliéndose, y la tabla anterior no tenía dónde guardarlo.

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | |
| `tripulante_id` | `$table->uuid('tripulante_id')->nullable();` | `NULL` = toda la tripulación |
| `modulo_nave_id` | `$table->uuid('modulo_nave_id')->nullable();` | **Nueva.** Módulo de la nave de un hallazgo ambiental global. Separa los episodios de `lab` y `nodo1` de la misma regla |
| `regla_codigo` | `$table->string('regla_codigo', 30);` | |
| `familia` | `$table->string('familia', 30);` | Para que M13 agrupe y escale |
| `sistema` | `$table->string('sistema', 10);` | |
| `nivel` | `$table->string('nivel', 8);` | `info`, `aviso` o `critico` |
| `explicacion` | `$table->json('explicacion');` | Formato de [backend §3.5](../../backend/README.md#35-explicación-hu-1203) |
| `ventana_desde`, `ventana_hasta` | `$table->dateTime(..., 3);` | Datos evaluados; `ventana_hasta` avanza mientras el episodio sigue abierto |
| `valor_extremo` | `$table->decimal('valor_extremo', 12, 4)->nullable();` | **Nueva.** El peor valor del episodio |
| `ocurrencias` | `$table->unsignedSmallInteger('ocurrencias')->default(1);` | **Nueva.** Ventanas de persistencia completadas en el episodio |
| `abierto` | `$table->boolean('abierto')->default(true);` | **Nueva.** `false` cuando la condición deja de cumplirse |
| `detectado_en` | `$table->dateTime('detectado_en', 3);` | Primera detección |
| `actualizado_en` | `$table->dateTime('actualizado_en', 3);` | **Nueva** |

- **Índices:** `(tripulante_id, regla_codigo, abierto)` (buscar el episodio abierto), `(tripulante_id, detectado_en)` (reporte diario de M14) y `(modulo_nave_id, regla_codigo, abierto)`.
- `hallazgos` **se actualiza** (episodio abierto): es un registro de trabajo del motor, no una medición.
