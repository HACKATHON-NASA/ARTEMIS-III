## Especificación

**`lineas_base`** (ya existe; columnas en la [ficha](../README.md#1-tablas)). **Qué `contexto` lleva cada línea base**, para que todos los módulos la busquen igual:

| Variables | `contexto` |
|---|---|
| Vitales (`8867-4`, `59408-5`, `9279-1`, `8310-5`, `8480-6`, `8462-4`, `AH-RMSSD`) | `reposo` y, si hay lecturas de sueño, otra con `sueno` |
| Sueño (`AH-SUENO-DURACION`, `AH-SUENO-EFICIENCIA`) | `NULL` |
| Masa corporal (`29463-7`) | `NULL` |
| Métricas cognitivas (`AH-PVT-*`, `AH-ARIT-*`, `AH-MEM-SPAN`) | `NULL` |

**Migración nueva `create_solicitudes_recalculo`** (la ficha mencionaba el recálculo pero no tenía dónde guardar la solicitud mientras viaja a la nave):

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | La genera la Tierra; es la misma en los dos nodos |
| `tripulante_id` | `$table->uuid('tripulante_id');` | |
| `codigo` | `$table->string('codigo', 20);` | |
| `contexto` | `$table->string('contexto', 10)->nullable();` | |
| `ventana_desde`, `ventana_hasta` | `$table->date('ventana_desde');` y `ventana_hasta` | Días que se usarán |
| `motivo` | `$table->string('motivo', 300);` | Obligatorio |
| `solicitado_por` | `$table->unsignedBigInteger('solicitado_por');` | Médico de vuelo |
| `estado` | `$table->string('estado', 12);` | `pendiente`, `completada` o `rechazada` |
| `linea_base_id` | `$table->uuid('linea_base_id')->nullable();` | La línea base que creó la nave |
| `motivo_rechazo` | `$table->string('motivo_rechazo', 200)->nullable();` | P. ej., "Menos de 10 lecturas en la ventana" |
| `created_at`, `updated_at` | `$table->datetimes(3);` | Es un registro de trabajo: cambia de estado |

- **Índice:** `(tripulante_id, estado)`.
