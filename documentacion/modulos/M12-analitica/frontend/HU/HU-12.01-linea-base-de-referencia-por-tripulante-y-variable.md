## Página `Tierra/LineasBase/Index` (`/tierra/tripulantes/{codigo}/lineas-base`)

```
┌──────────────────────────────────────────────────────────────────────────┐
│ Líneas base · T2                                                         │
│                                                                          │
│ Variable                 Contexto  Media ± σ     n     Fuente              │
│ Frecuencia cardiaca      Reposo    61 ± 3 lpm    10    Previa al vuelo  [Recalcular] │
│ Frecuencia cardiaca      Sueño     55 ± 4 lpm    2.940 Días 1–7         [Recalcular] │
│ SpO₂                     Reposo    98 ± 1 %      7.120 Días 1–7         [Recalcular] │
│ Mediana del PVT          —         281 ± 9 ms    5     Días 1–7 (sesiones 3–7)       │
│                                                                          │
│ Solicitudes de recálculo                                                 │
│ FC · Reposo · 1–10 nov  ↻ Pendiente (llegará a la nave hacia 14:17 UTC)  │
│                                                                          │
│ ▸ Historial (líneas base anteriores)                                     │
└──────────────────────────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Tabla de vigentes | Variable, contexto ("Reposo", "Sueño" o "—"), media ± σ con su unidad, `n` y fuente en texto. Las cognitivas no tienen "Recalcular" (las calcula su regla) |
| "Recalcular" | Diálogo en **dos pasos**. Paso 1: "Desde" y "Hasta" (de 3 a 30 días, en el pasado) y "Motivo" (obligatorio, ≤ 300). Paso 2, confirmación: "La nueva línea base cambiará la referencia de las alertas de <variable> de T2. ¿Enviar la solicitud a la nave?" con "Cancelar" · "Enviar solicitud" |
| Solicitudes | Estado con icono y texto: ↻ "Pendiente" (con la hora estimada de llegada de M15, si existe), ✓ "Completada", ✖ "Rechazada: <motivo>" |
| Historial | Plegado; las líneas base no vigentes con su fuente, fecha y quién autorizó |

## Criterios de aceptación

- **Dado** que pulso "Recalcular" sin motivo, **cuando** intento avanzar, **entonces** no puedo pasar al paso 2.
- **Dado** una solicitud rechazada, **cuando** se muestra, **entonces** dice "Rechazada" con su motivo.
- **Dado** una métrica cognitiva, **cuando** se muestra, **entonces** no tiene botón "Recalcular".
