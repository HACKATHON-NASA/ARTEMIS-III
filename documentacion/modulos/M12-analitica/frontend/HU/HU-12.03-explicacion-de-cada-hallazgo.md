## Componente `Analitica/Explicacion.vue` (lo usan M13 en las alertas y casos, y M14 en los reportes)

```
┌──────────────────────────────────────────────────────────────┐
│ Frecuencia cardiaca 128 lpm sostenida 5 min en reposo        │  ← texto, en grande
│ (rango 40–120). Línea base 61 ± 3 lpm (previa al vuelo).     │
│                                                              │
│ Regla         FC_REPOSO_LIMITES                              │
│ Valor         128 lpm                                        │
│ Umbral        Fuera de 40–120 lpm                            │
│ Línea base    61 ± 3 lpm · previa al vuelo                   │
│ Contexto      Reposo                                         │
│ Ventana       D12 · 10:00 → 10:05 UTC                        │
│ ▸ Datos relacionados                                         │
│     Sueño (4 noches): 4,9 h · Fatiga: 7/10                   │
└──────────────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Estructura | Primero `texto`. Debajo, una **lista de definiciones** (`<dl>`) con los campos presentes; los opcionales ausentes no aparecen |
| Datos relacionados | Plegados, con nombres legibles (`sueno_4_noches_h` → "Sueño (4 noches)", `fatiga_3d` → "Fatiga (3 días)", `pco2_max_horaria_24h` → "pCO₂ máxima horaria (24 h)", `rmssd_24h` → "VFC (24 h)") |
| Campo `confidencial` | **Solo** se muestra si `auth.permisos` incluye `ver-psicologia-detallada`; si no, ni siquiera aparece su título |
| Prop opcional `compacto` | Solo el texto, para las listas |

## Criterios de aceptación

- **Dado** una explicación sin `linea_base`, **cuando** se muestra, **entonces** no aparece la fila "Línea base".
- **Dado** una explicación con `confidencial` y un CMO, **cuando** se muestra, **entonces** no aparece; **con** el médico de vuelo, sí.
- **Dado** el modo `compacto`, **cuando** se muestra, **entonces** solo se ve el texto.
