## Página `Tierra/Tendencias/Show` (`/tierra/tripulantes/{codigo}/tendencias`)

```
┌──────────────────────────────────────────────────────────────────────┐
│ Tendencias · T2       Variable [Frecuencia cardiaca (reposo) ▾]      │
│                                                                      │
│ 7 días:  +3,2 lpm por semana (p = 0,01)                              │
│ 30 días: sin tendencia significativa                                 │
│                                                                      │
│  lpm   ░░░░░░░░░░░░ banda μ ± 2σ de la línea base                    │
│  70 ┤          ● ●  ╱ recta de la pendiente de 30 días               │
│  62 ┤ ● ● ● ●──────── EWMA (línea suave)                             │
│      D1 …………………………………… D30                                           │
└──────────────────────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Selector | Variables con datos; cambiar usa `router.get(url, { variable }, { preserveState: true })` |
| Pendiente en texto | "+3,2 lpm por semana (p = 0,01)". Si `p ≥ pMax` (hoy 0,05): "sin tendencia significativa". Si es `null`: "Pocos datos para calcularla" |
| `GraficaTendencia.vue` | Puntos de la media diaria, línea de la EWMA, banda μ ± 2σ de la línea base (si existe) y recta de la pendiente de 30 días |
| `p` | Con dos decimales; si es menor que 0,001: "p < 0,001" |

## Criterios de aceptación

- **Dado** `pendiente7 = { por_semana: 3.2, p: 0.012 }`, **cuando** se muestra, **entonces** dice "+3,2 lpm por semana (p = 0,01)".
- **Dado** `p = 0.2`, **cuando** se muestra, **entonces** dice "sin tendencia significativa".
- **Dado** `pendiente30 = null`, **cuando** se muestra, **entonces** dice "Pocos datos para calcularla".
