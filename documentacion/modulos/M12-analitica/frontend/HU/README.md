# M12 · Analítica y línea base · Historias de frontend

Trabajo de **Inertia + Vue 3 + Tailwind CSS v4** de M12: qué páginas hay, **cómo deben verse**, qué textos llevan y cómo se comportan. Lo hacen **Jhon** (HU-12.01 y HU-12.04) y **Gabriela** (HU-12.03). HU-12.02 no tiene pantalla. Las *props* vienen de las [historias de backend](../../backend/HU/README.md).

## Reglas comunes

- Se siguen la [guía visual provisional](../../../M01-identidad/frontend/HU/README.md#guía-visual-provisional) y la [estructura común de las aplicaciones](../../../M01-identidad/frontend/HU/README.md#estructura-común-de-las-cuatro-aplicaciones) de M01.
- Nombres, unidades y decimales de las variables: los de [M04](../../../M04-signos-vitales/frontend/HU/README.md) (vitales) y de cada módulo para el resto.
- **Fuente de una línea base en texto:** `previa_vuelo` "previa al vuelo", `ventana_inicial` "días 1–7 de misión", `recalculo_autorizado` "recálculo autorizado".
