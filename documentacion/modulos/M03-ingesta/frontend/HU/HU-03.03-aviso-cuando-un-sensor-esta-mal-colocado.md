## Componente `EstadoSensores.vue` (`resources/js/components/EstadoSensores.vue`)

Va arriba del todo en el inicio de F1 (`/astronauta`), debajo de la cabecera y antes de cualquier otro contenido.

```
Revisar colocación (uno o varios dispositivos)
┌──────────────────────────────────────────────────────────────┐
│ ⚠  Reacomoda el sensor del pecho (astroskin-T2)              │
│    Comprueba que esté bien colocado. Desde las 14:05 UTC.    │
└──────────────────────────────────────────────────────────────┘

Sin datos (se agrupan en una sola tarjeta)
┌──────────────────────────────────────────────────────────────┐
│ ○  2 sensores sin datos: oxímetro (oximetro-T2) desde hace   │
│    14 min, dosímetro (dosimetro-T2) desde hace 2 h.          │
│    Comprueba que estén encendidos.                           │
└──────────────────────────────────────────────────────────────┘

Sin conexión
┌──────────────────────────────────────────────────────────────┐
│ ⚠  Reacomoda el sensor del pecho (astroskin-T2)              │
│    …                                                         │
│    Estado de hace 12 min (sin conexión).                     │
└──────────────────────────────────────────────────────────────┘
```

**Prop** (del controlador del inicio de F1)

```ts
estadoSensores: { identificador: string, tipo: TipoDispositivo,
                  estado: 'ok' | 'revisar_colocacion' | 'sin_datos',
                  desde: string | null }[]
```

**Nombre del sensor en el mensaje** (según `tipo`):

| `tipo` | En "Reacomoda …" | En la lista de "sin datos" |
|---|---|---|
| `wearable` | el sensor del pecho | sensor del pecho |
| `oximetro` | el oxímetro | oxímetro |
| `tensiometro` | el tensiómetro | tensiómetro |
| `actigrafo` | el actígrafo | actígrafo |
| `dosimetro` | el dosímetro | dosímetro |
| `cgm` | el monitor de glucosa | monitor de glucosa |
| `medidor_masa` | el medidor de masa | medidor de masa |

| Elemento | Especificación |
|---|---|
| `revisar_colocacion` | **Una tarjeta por dispositivo**, con fondo de aviso suave (no rojo), icono ⚠ y el texto "Reacomoda <nombre> (<identificador>)". Segunda línea: "Comprueba que esté bien colocado. Desde las <HH:MM> UTC." (hora de `desde`). La ficha anterior enlazaba a unas "instrucciones de colocación" que no existen; se quita el enlace |
| `sin_datos` | **Una sola tarjeta** neutra para todos, con icono ○: "N sensores sin datos: <nombre> (<identificador>) desde hace <tiempo>, …" y "Comprueba que estén encendidos.". Con un solo sensor: "Sin datos del <nombre> (<identificador>) desde hace <tiempo>. Comprueba que esté encendido." Si `desde` es `null`: "nunca ha enviado datos". Solo pueden aparecer aquí los dispositivos de envío continuo (sensor del pecho, oxímetro, dosímetro y monitor de glucosa): el backend nunca marca así el tensiómetro, el actígrafo ni el medidor de masa |
| Orden | Primero las tarjetas de colocación y después la de sin datos |
| Todo `ok` (o lista vacía) | No se muestra nada |
| Tiempo relativo | "hace 3 min", "hace 2 h", "hace 1 día" |
| Refresco | `usePoll(10000, { only: ['estadoSensores'] })` |
| Sin conexión | Usa la última copia guardada en `instantaneas` (M15) y añade "Estado de hace <tiempo> (sin conexión)." |
| Desaparición | Cuando un sensor vuelve a `ok`, su tarjeta desaparece en el siguiente refresco, sin animación |
| Móvil | Las tarjetas ocupan todo el ancho; el texto se ajusta en varias líneas |

## Accesibilidad

- El contenedor tiene `role="status"` y `aria-live="polite"`: el lector de pantalla anuncia un aviso nuevo sin interrumpir.
- El estado nunca depende solo del color: lleva icono y texto.

## Criterios de aceptación

- **Dado** `astroskin-T2` en `revisar_colocacion` desde las 14:05, **cuando** se muestra el inicio, **entonces** aparece "Reacomoda el sensor del pecho (astroskin-T2)" y "Desde las 14:05 UTC.".
- **Dado** dos sensores `sin_datos`, **cuando** se muestra el inicio, **entonces** aparece una sola tarjeta con los dos.
- **Dado** que todos están `ok`, **cuando** se muestra el inicio, **entonces** no aparece ninguna tarjeta.
- **Dado** que el sensor vuelve a `ok`, **cuando** llega el siguiente refresco, **entonces** su tarjeta desaparece.
- **Dado** que no hay conexión, **cuando** se abre el inicio, **entonces** se muestra la última copia con "Estado de hace … (sin conexión).".
- **Dado** E6 en vivo, **cuando** el astronauta T mira su inicio, **entonces** ve el aviso del sensor del pecho y no suena ninguna alarma.
