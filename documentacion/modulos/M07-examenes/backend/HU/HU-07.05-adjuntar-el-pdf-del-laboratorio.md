**Como** astronauta, **quiero** adjuntar el PDF del laboratorio a mis resultados, **para** conservar el documento original.

| Prioridad | Sprint | Responsable | Depende de | Historia completa |
|---|:---:|---|---|---|
| Could | 2 | Julieth | HU-07.01 | 2 pts |

## Especificación

**1. `POST /astronauta/examenes/documentos`** (web, sesión, Gate `ver-datos-propios`, requiere conexión), *multipart*:

| Campo | Regla (`DocumentoRequest`) | Mensaje |
|---|---|---|
| `fecha_muestra` | `AAAA-MM-DD`, no futura | — |
| `archivo` | `file`, `mimetypes:application/pdf` (Laravel lo comprueba **por el contenido**, no por la extensión), `max:2048` (KB, de `adjunto_pdf_max_kb`) | "El archivo debe ser un PDF de hasta 2 MB." |

**2. Guardado** (`AdjuntarDocumento`): calcula `sha256`. Si el vigente de esa fecha tiene el mismo `sha256`, no guarda nada ("Este PDF ya está adjunto."). Si no, guarda el archivo en `examenes/<tripulante_id>/<id>.pdf` del disco `local` y la fila con `anula_id` = el vigente anterior (si lo hay). Si falla la base, se borra el archivo escrito.

**3. `GET /examenes/documentos/{id}`:** descarga con `Storage::disk('local')->download(ruta, nombre_original)`. Permiso (`DocumentoPolicy::descargar`): el propio tripulante, o un usuario con `ver-datos-tripulacion` (`cmo`, `medico_vuelo`). Si no → `403`. Auditoría `ver` (`recurso_tipo = documentos_examen`) cuando lo descarga otra persona.

**4. Envío a la Tierra** (parte de HU-15.01, Sprint 3): `ColaSincronizacion::encolar('adjunto', 3, { tipo: 'documento_examen', fila, contenido_base64 })`. El `Importador` de M07 en la Tierra escribe el archivo y la fila con su mismo `id`.

## Criterios de aceptación

- **Dado** un `.pdf` que en realidad es una imagen PNG, **cuando** se sube, **entonces** responde con el error de tipo.
- **Dado** un PDF de 3 MB, **cuando** se sube, **entonces** responde con el error de tamaño.
- **Dado** el mismo PDF dos veces para la misma fecha, **cuando** llega el segundo, **entonces** no se crea otra fila.
- **Dado** un PDF nuevo para una fecha que ya tenía uno, **cuando** se sube, **entonces** el nuevo es el vigente y el anterior se conserva.
- **Dado** T3, **cuando** pide el PDF de T2, **entonces** recibe `403`; **y el** CMO puede descargarlo.
