## Página `Astronauta/Examenes/Create` (`/astronauta/examenes/cargar`)

```
┌──────────────────────────────────────────────────────────────┐
│ Cargar resultados                    [Importar CSV →]        │
│                                                              │
│ Fecha de la muestra  [2026-11-10]  (no la de hoy, si es otra)│
│                                                              │
│ Prueba                         Valor        Unidad           │
│ [Hemoglobina          ▾]       [ 13,4 ]     g/dL   (fija)  ✕ │
│ [Hematocrito          ▾]       [ 40,2 ]     %      (fija)  ✕ │
│ [+ Añadir otra prueba]                                        │
│                                                              │
│                              [Cancelar] [Guardar resultados] │
└──────────────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Fecha de la muestra | Obligatoria, por defecto hoy, máximo `fechaMaxima`. Debajo: "Usa la fecha en que se tomó la muestra, no la de hoy." |
| Prueba | Desplegable con búsqueda por nombre, agrupado en "Laboratorio" e "Imagen" |
| Unidad | **Se rellena sola** con la del catálogo y no se puede editar (texto, no campo) |
| Valor | `inputmode="decimal"`, admite coma; se envía con punto |
| Varias pruebas | Una fila por prueba, todas con la misma fecha; una prueba no se puede repetir en el mismo envío |
| Guardar | Un `id` por fila; se encola en `/api/v1/examenes/resultados`. "Guardado en el dispositivo" y vuelve a "Mis exámenes" |

## Página `Astronauta/Examenes/Importar` (`/astronauta/examenes/importar`)

```
Paso 1                                        Paso 2 (vista previa)
┌───────────────────────────────────────┐     ┌────────────────────────────────────────────────┐
│ Importar resultados desde un CSV      │     │ 12 filas válidas · 1 con errores               │
│ Formato: fecha_muestra,codigo_prueba, │     │ Fila  Fecha       Prueba        Valor  Estado   │
│ valor,unidad (punto decimal)          │     │  2    2026-11-10  Hemoglobina   13,1   ✓        │
│ [Descargar ejemplo]                   │     │  3    2026-11-10  Hemoglobina   13,3   ↻ Corrige 13,1 → 13,3 │
│ [Elegir archivo…]  (máx. 1 MB)        │     │  4    2026-11-10  Hematocrito   —      ✖ La unidad de Hematocrito debe ser % │
│            [Ver vista previa]         │     │                    [Cancelar] [Guardar 12 filas válidas] │
└───────────────────────────────────────┘     └────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| "Descargar ejemplo" | Un CSV de ejemplo con la cabecera y las 3 filas de [04 §6.2](../../../../docs/propuesta/04-manejo-de-datos.md#62-formato-de-carga-por-csv), generado en el navegador |
| Vista previa (`TablaVistaPrevia.vue`) | Una fila por línea del CSV: ✓ válida, ↻ corrección (con el valor anterior y el nuevo), ✖ errónea (con el motivo en la misma fila) |
| Guardar | "Guardar N filas válidas" (las correcciones cuentan como válidas). Se deshabilita al pulsarlo, para no enviarlo dos veces |
| Sin filas válidas | El botón no aparece; texto "No hay filas válidas para guardar." |

## Criterios de aceptación

- **Dado** que elijo "Hemoglobina", **cuando** miro la fila, **entonces** la unidad dice "g/dL" y no se puede cambiar.
- **Dado** que escribo "13,4", **cuando** se envía, **entonces** el cuerpo lleva `13.4`.
- **Dado** que no hay conexión, **cuando** abro "Importar CSV", **entonces** el botón está deshabilitado con "Requiere conexión".
- **Dado** una vista previa con 1 error y 12 válidas, **cuando** se muestra, **entonces** el error está en su fila con el motivo y el botón dice "Guardar 12 filas válidas".
