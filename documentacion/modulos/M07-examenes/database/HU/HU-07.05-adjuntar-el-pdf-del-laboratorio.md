## Especificación

**Migración `create_documentos_examen`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | Lo genera el servidor |
| `tripulante_id` | `$table->uuid('tripulante_id');` | |
| `fecha_muestra` | `$table->date('fecha_muestra');` | Agrupa el PDF con los resultados de esa fecha |
| `nombre_original` | `$table->string('nombre_original', 150);` | Sin rutas; caracteres de control eliminados |
| `ruta` | `$table->string('ruta', 255);` | `examenes/<tripulante_id>/<id>.pdf` en el disco `local` (antes `storage/app/privado/…`, que no es la raíz del disco privado de Laravel 11) |
| `bytes` | `$table->unsignedInteger('bytes');` | ≤ `adjunto_pdf_max_kb` × 1024 (M16: 2048 KB) |
| `sha256` | `$table->char('sha256', 64);` | **Nueva.** Para detectar que se sube dos veces el mismo archivo |
| `cargado_por` | `$table->unsignedBigInteger('cargado_por');` | |
| `anula_id` | `$table->uuid('anula_id')->nullable();` + clave foránea a `documentos_examen.id` | **Sustituye** a `anulado_por`: el documento nuevo apunta al que reemplaza |
| `created_at` | `$table->dateTime('created_at', 3);` | |

- **Índice:** `(tripulante_id, fecha_muestra)`.

## Criterios de aceptación

- **Dado** el PDF del día 10 y después otro del mismo día, **cuando** consulto el vigente, **entonces** es el segundo, y el primero sigue en la base y en el disco.
