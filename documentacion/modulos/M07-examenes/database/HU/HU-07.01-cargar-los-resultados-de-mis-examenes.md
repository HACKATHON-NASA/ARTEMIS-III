## Especificación

**Migración `create_resultados_examen`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | Del cliente (formulario y simulador) o del servidor (CSV) |
| `tripulante_id` | `$table->uuid('tripulante_id');` | Lógica (M02) |
| `prueba_codigo` | `$table->string('prueba_codigo', 20);` | Lógica (`catalogo_pruebas` de M16) |
| `fecha_muestra` | `$table->date('fecha_muestra');` | Define el orden; **no** la fecha de carga |
| `valor` | `$table->decimal('valor', 12, 4);` | |
| `unidad` | `$table->string('unidad', 20);` | Igual a la del catálogo |
| `interpretacion` | `$table->string('interpretacion', 10);` | `bajo`, `normal`, `alto` o `critico`, con el rango vigente **al cargar** |
| `delta_superado` | `$table->boolean('delta_superado')->default(false);` | Se calcula desde HU-07.02 |
| `tendencia_desfavorable` | `$table->boolean('tendencia_desfavorable')->default(false);` | Se calcula desde HU-07.02 |
| `origen` | `$table->string('origen', 10);` | `formulario`, `csv` o `simulador` |
| `cargado_por` | `$table->unsignedBigInteger('cargado_por')->nullable();` | Usuario; `NULL` si lo cargó el simulador |
| `anula_id` | `$table->uuid('anula_id')->nullable();` + clave foránea a `resultados_examen.id` | Corrección de otro resultado de la misma prueba y fecha de muestra |
| `created_at` | `$table->dateTime('created_at', 3);` | |

- **Índices:** `(tripulante_id, prueba_codigo, fecha_muestra)`, `(tripulante_id, fecha_muestra)` y el de `anula_id` (lo crea la clave foránea).
- **Un vigente por prueba y fecha de muestra:** lo garantiza el caso de uso con un bloqueo con nombre `Cache::lock("examen:{tripulante}:{prueba}:{fecha}", 10)`, porque MySQL no tiene índices únicos parciales.

## Criterios de aceptación

- **Dado** un resultado de Hb del 10 y una corrección del mismo día, **cuando** consulto los vigentes, **entonces** solo aparece la corrección.
- **Dado** un valor de `13.15`, **cuando** lo leo, **entonces** vale `13.1500`.
