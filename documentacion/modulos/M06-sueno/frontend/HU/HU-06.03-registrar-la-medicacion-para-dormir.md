## Página `Astronauta/Sueno/Create` (`/astronauta/sueno/registrar`)

```
Con actigrafía de esa noche (yaExiste)         Sin actigrafía
┌──────────────────────────────────────┐       ┌──────────────────────────────────────┐
│ Noche del 12 al 13 de noviembre      │       │ Noche del 12 al 13 de noviembre      │
│ ✓ El actígrafo registró 6,4 h (90 %).│       │ Me acosté   [23:00] UTC              │
│                                      │       │ Me desperté [07:00] UTC              │
│ ¿Tomaste medicación para dormir?     │       │ Horas dormidas (aprox.) [ 6,5 ]      │
│ (•) No   ( ) Sí  [Nombre      ]      │       │                                      │
│                                      │       │ ¿Tomaste medicación para dormir?     │
│ Luz en el módulo   Nada ○──●──○ Mucha│       │ (•) No   ( ) Sí  [Nombre      ]      │
│ Ruido              Nada ○────●○ Mucho│       │ Luz …   Ruido …                      │
│                         [Guardar]    │       │                         [Guardar]    │
└──────────────────────────────────────┘       └──────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Noche | Arriba, con las dos fechas de `nocheSugerida`. Debajo, el enlace "Es otra noche" despliega un selector de fecha de despertar (hasta 7 días atrás); al cambiarlo, se recalcula la noche que se muestra. `yaExiste` solo describe la noche sugerida: para otra noche se muestra el formulario completo (horarios opcionales) y el servidor fusiona si ya había actigrafía |
| Con `yaExiste` medido | No se piden horarios: "✓ El actígrafo registró 6,4 h (90 %)." Solo medicación, luz y ruido |
| Sin `yaExiste` | "Me acosté" y "Me desperté" (hora UTC; el despertar viene prellenado con `despertadoSugerido`) y "Horas dormidas (aprox.)". **No** se pide la eficiencia: la calcula el servidor. Si las horas superan el tiempo en cama: "Las horas dormidas no pueden superar el tiempo en cama." |
| Medicación | Botones "No" / "Sí". Con "Sí", aparece "Nombre (opcional)" |
| Luz y ruido | Deslizadores 0–10, opcionales (empiezan sin valor) |
| Guardar | Genera el `id`, arma el cuerpo y lo encola en `/api/v1/sueno/registros`. Confirma "Guardado en el dispositivo" y vuelve a `Mi sueño` |

## Criterios de aceptación

- **Dado** `yaExiste` con 6,4 h del actígrafo, **cuando** abro la página, **entonces** no aparecen los campos de horario y veo "El actígrafo registró 6,4 h (90 %)".
- **Dado** que me acosté a las 23:00, desperté a las 07:00 y escribo 9 horas, **cuando** salgo del campo, **entonces** veo el error y "Guardar" está deshabilitado.
- **Dado** que no hay conexión, **cuando** guardo, **entonces** el registro queda en la cola con su `despertado_en`.
- **Dado** que cambio a "Es otra noche" y elijo despertar el día 10, **cuando** se actualiza, **entonces** dice "Noche del 9 al 10 de …".
