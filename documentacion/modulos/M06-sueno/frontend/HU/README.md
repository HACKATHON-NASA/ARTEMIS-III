Trabajo de **Inertia + Vue 3 + Tailwind CSS v4** de M06: qué páginas hay, **cómo deben verse**, qué textos llevan y cómo se comportan. Lo hace **Jhon**. HU-06.02 no tiene pantalla propia (el aviso lo muestra M13). Las *props* vienen de las [historias de backend](../../backend/HU/README.md).

## Reglas comunes

- Se siguen la [guía visual provisional](../../../M01-identidad/frontend/HU/README.md#guía-visual-provisional) y la [estructura común de las aplicaciones](../../../M01-identidad/frontend/HU/README.md#estructura-común-de-las-cuatro-aplicaciones) de M01. Textos para el astronauta **de tú**.
- **Una noche se nombra por sus dos fechas:** "Noche del 12 al 13 de noviembre" (la `noche` es la primera fecha). En listas cortas, con el día de misión: "D12→D13".
- **Horas con coma decimal y una cifra** ("6,4 h"); eficiencia sin decimales ("90 %").
- **Una noche "mala"** (según los umbrales que llegan en las *props*) se marca con icono ☾✕ y el texto "Noche corta" o "Baja eficiencia", nunca solo con color. No es una alerta: la alerta (3 noches seguidas) la muestra M13.
