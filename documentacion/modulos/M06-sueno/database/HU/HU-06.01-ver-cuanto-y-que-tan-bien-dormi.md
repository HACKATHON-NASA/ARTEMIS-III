## Especificación

**Migración `create_registros_sueno`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | Generado en el cliente; en una fusión, lo genera el servidor |
| `tripulante_id` | `$table->uuid('tripulante_id');` | Lógica (M02) |
| `noche` | `$table->date('noche');` | Fecha UTC de (`despertado_en` − 12 h); la calcula el servidor |
| `acostado_en` | `$table->dateTime('acostado_en', 3)->nullable();` | `NULL` solo en un registro manual sin horarios |
| `despertado_en` | `$table->dateTime('despertado_en', 3);` | **Siempre obligatorio** (define la noche) |
| `duracion_h` | `$table->decimal('duracion_h', 4, 2)->nullable();` | Tiempo dormido; `NULL` si el registro es solo de medicación |
| `eficiencia_pct` | `$table->decimal('eficiencia_pct', 5, 2)->nullable();` | **La calcula el servidor**: `duracion_h / (despertado_en − acostado_en en horas) × 100`. `NULL` si falta la duración o la hora de acostarse |
| `origen` | `$table->string('origen', 10);` | `actigrafia`, `manual` o `simulador`. **Lo decide el servidor según el token** |
| `medicacion` | `$table->boolean('medicacion')->nullable();` | `NULL` = no se sabe (la actigrafía no lo informa); `true`/`false` lo dice el registro manual |
| `medicacion_nombre` | `$table->string('medicacion_nombre', 60)->nullable();` | |
| `luz_percibida`, `ruido_percibido` | `$table->unsignedTinyInteger(...)->nullable();` | 0 (nada) a 10 (mucho) |
| `anula_id` | `$table->uuid('anula_id')->nullable();` + `->foreign('anula_id')->references('id')->on('registros_sueno')` | Registro anterior al que sustituye |
| `created_at` | `$table->dateTime('created_at', 3);` | |

- **Índices:** `(tripulante_id, noche)` y el de `anula_id`, que crea la clave foránea. La ficha anterior proponía `(tripulante_id, noche, anula_id)`, que no sirve para saber si un registro **está anulado** (esa consulta busca por `anula_id = <id>`).
- `medicacion` pasa a admitir `NULL`: con `boolean NOT NULL`, una noche del actígrafo guardaría `false` ("no tomó medicación") sin que nadie lo dijera.

**Consulta del registro vigente de una noche:**

```sql
SELECT r.* FROM registros_sueno r
WHERE r.tripulante_id = ? AND r.noche = ?
  AND NOT EXISTS (SELECT 1 FROM registros_sueno x WHERE x.anula_id = r.id);
```

**Volumen:** una fila por tripulante y noche, más las fusiones: ~120–240 filas al mes para 4 tripulantes.

## Criterios de aceptación

- **Dado** un registro A y una fusión B con `anula_id = A`, **cuando** consulto el vigente de esa noche, **entonces** obtengo B.
- **Dado** una noche del actígrafo, **cuando** se guarda, **entonces** `medicacion` es `NULL`.
