## Especificación

**1. `POST /api/v1/signos-vitales/ecg`**: `auth:sanctum` + `TokenDeTipo:dispositivo`. **Misma autorización que un lote de M03**: el token debe ser del dispositivo nombrado, o del simulador, y el dispositivo debe estar asignado a ese tripulante.

```json
{ "id": "uuid", "dispositivo_id": "astroskin-T2", "tripulante_id": "T2", "inicio": "2026-11-09T14:00:00Z",
  "frecuencia_muestreo_hz": 250, "contexto": "reposo", "muestras": [0.012, …], "picos_r": [52, 301, …], "qtc_ms": 402 }
```

| Campo | Regla |
|---|---|
| `frecuencia_muestreo_hz` | Entero 100–1000 |
| `muestras` | Array de números; longitud ≤ 60 × frecuencia (≤ 60 s) |
| `picos_r` | Array de enteros **estrictamente crecientes**, cada uno entre 0 y `count(muestras) − 1` |
| `contexto` | `reposo`, `ejercicio` o `sueno` |
| `qtc_ms` | Opcional, entero 250–700 (rango de `AH-QTC`) |
| `inicio` | ISO 8601, no más de 5 minutos en el futuro |

**2. Métricas** (`Domain/Reglas/MetricasRitmo.php`, clase pura):

| Métrica | Fórmula | Condición |
|---|---|---|
| RR (ms) | `(picos_r[i+1] − picos_r[i]) × 1000 / frecuencia` | — |
| `n_rr` | Número de RR | — |
| `fc_media` | `60000 / media(RR)`, 1 decimal | `n_rr ≥ 10`; si no, `NULL` |
| `pausa_max_s` | `max(RR) / 1000`, 2 decimales | `n_rr ≥ 10` |
| `cv_rr` | `desviación estándar muestral(RR) / media(RR)`, 4 decimales | `n_rr ≥ 30` |

**3. Guardado:** en una transacción, la fila de `ventanas_ecg` y el archivo `ecg/<tripulante_id>/<id>.json` en el disco `local`. Si el `id` ya existe: `200` sin reescribir nada. Si falla la base, se borra el archivo escrito. Respuesta `201` con `{ id, n_rr, fc_media, pausa_max_s, cv_rr }`.

**4. Rutas web:**

| Ruta | Gate y nodo | Página |
|---|---|---|
| `GET /tierra/tripulantes/{codigo}/ecg` | `ver-datos-tripulacion`, Tierra | `Tierra/Ecg/Index`: ventanas paginadas (20), de la más reciente a la más antigua |
| `GET /tierra/tripulantes/{codigo}/ecg/{ventana}` | `ver-datos-tripulacion`, Tierra | `Tierra/Ecg/Show`: métricas + `muestras` y `picos_r` leídos del archivo |
| `GET /cmo/tripulantes/{codigo}/ecg/{ventana}` | `ver-datos-tripulacion`, nave | `Cmo/Ecg/Show` (mismas *props*) |

Las tres páginas reciben también `umbrales: { pausa_s, cv_rr, qtc_ms }` (valores vigentes de `ECG_PAUSA`, `ECG_IRREGULAR` y `ECG_QTC` en M16), para marcar en pantalla las métricas que los superan. Si la ventana no es de ese tripulante → `404`. Abrir una ventana → auditoría `ver` (`recurso_tipo = ventanas_ecg`).

**5. El simulador antes del Sprint 4.** El simulador envía una ventana al día desde el Sprint 1, pero este endpoint no existe hasta ahora. La [ficha del simulador](../../../simulador/README.md) indica que **un `404` en un endpoint aún no construido se omite con un aviso** y el comando sigue.

## Parte B (Sprint 4, dentro de HU-15.02) · ECG en la Tierra

- Las ventanas viajan en el paquete `detalle` (prioridad 3) **con el contenido del archivo** en el *payload*.
- El `Importador` de M04 inserta la fila con su mismo `id` y escribe el archivo. Si ya existe, no hace nada.

## Criterios de aceptación

- **Dado** picos con RR = [800, 800, 3200, 800, …] (12 RR), **cuando** se calculan las métricas, **entonces** `pausa_max_s = 3.20`.
- **Dado** 59 RR de 1000 ms, **cuando** se calculan, **entonces** `fc_media = 60.0` y `cv_rr = 0.0000`.
- **Dado** 8 RR, **cuando** se guarda, **entonces** `fc_media`, `pausa_max_s` y `cv_rr` son `NULL`.
- **Dado** `picos_r` no crecientes, **cuando** se envía, **entonces** responde `422`.
- **Dado** el token de `astroskin-T2`, **cuando** envía una ventana de T3, **entonces** responde `403`.
- **Dado** la misma ventana dos veces, **cuando** llega la segunda, **entonces** responde `200` y el archivo no se reescribe.
- **Dado** el médico de vuelo en la Tierra, **cuando** abre una ventana, **entonces** recibe sus 15.000 muestras y sus picos R.
