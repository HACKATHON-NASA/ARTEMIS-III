## Página `Cmo/Ortostatica/Create` (`/cmo/ortostatica/crear`)

```
┌──────────────────────────────────────────────────────────────────────┐
│ Prueba ortostática                                                   │
│                                                                      │
│ Tripulante   [ T3 · Diego Salas            ▾ ]                       │
│ Modalidad    (•) LBNP en vuelo   ( ) De pie (en gravedad)            │
│              ℹ En microgravedad no se puede poner de pie: se usa     │
│                presión negativa en la parte inferior del cuerpo.     │
│ Fecha y hora [2026-11-03] [09:10] UTC                                │
│                                                                      │
│                  Basal (acostado)      Con estímulo (LBNP)           │
│ FC (lpm)         [ 64 ]                [ 82 ]                        │
│ PAS (mmHg)       [118 ]                [ 96 ]                        │
│ PAD (mmHg)       [ 76 ]                [ 70 ]                        │
│                                                                      │
│ ┌──────────────────────────────────────────────────────────────────┐ │
│ │ Caída sistólica 22 mmHg (umbral 20) · diastólica 6 mmHg (umbral 10) │
│ │ ⚠ Resultado previsto: POSITIVA                                    │ │
│ └──────────────────────────────────────────────────────────────────┘ │
│                                             [Cancelar] [Registrar]   │
└──────────────────────────────────────────────────────────────────────┘
```

| Elemento | Especificación |
|---|---|
| Modalidad | Botones de opción "LBNP en vuelo" (marcada por defecto) y "De pie (en gravedad)", con el texto de ayuda. La columna "Con estímulo" cambia su título: "(LBNP)" o "(de pie)" |
| Fecha y hora | Por defecto, ahora (UTC) |
| Campos numéricos | `inputmode="numeric"`, enteros. Validación inmediata con los mismos rangos del backend (FC 20–250, PAS 50–260, PAD 30–160, PAD < PAS) |
| Resultado previsto | Aparece cuando las 6 tomas son válidas. Calcula las caídas con la misma fórmula y los `umbrales` de las *props*. "POSITIVA" con icono ⚠ o "Normal" con ✔ (texto, no solo color). Una caída negativa se muestra como "sube 5 mmHg" |
| Registrar | Genera el `id` con `crypto.randomUUID()` y llama a `encolar('/api/v1/signos-vitales/ortostatica', cuerpo)` (M15). Confirma con "Guardado en el dispositivo. Se enviará al servidor." y vuelve al tripulante en F2 |
| Aviso | Debajo del resultado, en pequeño: "Umbral de <sistólica>/<diastólica> mmHg pendiente de validación médica para la modalidad LBNP." (valores de `umbrales`, hoy 20/10) solo si la modalidad es `lbnp` |

## Criterios de aceptación

- **Dado** las tomas del boceto, **cuando** están completas, **entonces** se ve "Caída sistólica 22 mmHg" y "Resultado previsto: POSITIVA".
- **Dado** una PAD mayor que la PAS, **cuando** salgo del campo, **entonces** veo "La diastólica debe ser menor que la sistólica." y "Registrar" está deshabilitado.
- **Dado** que no hay conexión, **cuando** pulso "Registrar", **entonces** la prueba queda en la cola con su `id` y se ve el mensaje de guardado.
- **Dado** el umbral sistólico en 25 (*props*), **cuando** la caída es 22/6, **entonces** el resultado previsto es "Normal".
