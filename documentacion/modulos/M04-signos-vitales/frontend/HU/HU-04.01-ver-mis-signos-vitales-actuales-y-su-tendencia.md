## Página `Astronauta/Inicio` (`/astronauta`, reemplaza la temporal de M01)

```
┌──────────────────────────────────────────────────────────────────────┐
│ Mi salud                    [● Nave] Día 12 de misión   Laura ▾     │
├──────────────────────────────────────────────────────────────────────┤
│ ⚠ Reacomoda el sensor del pecho (astroskin-T2)       ← EstadoSensores (M03) │
│                                                                      │
│ Estado por sistema                                   ← desde el Sprint 3 │
│ [✔ Corazón] [✔ Sueño] [⚠ Mente] [✔ Radiación] [✔ Cuerpo]            │
│                                                                      │
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐  │
│ │ Frec. cardiaca│ │ SpO₂         │ │ Temperatura  │ │ Presión      │  │
│ │ 72 lpm  ↑    │ │ 98 %   →     │ │ 36,8 °C →    │ │ 118/76 mmHg  │  │
│ │ hace 1 min   │ │ hace 1 min   │ │ hace 3 min   │ │ hoy 07:30    │  │
│ └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘  │
│                                         [Ver mis signos vitales →]   │
└──────────────────────────────────────────────────────────────────────┘
```

- **Semáforo:** una fila de 5 sistemas (`corazon`, `sueno`, `mente`, `radiacion`, `cuerpo`) con el componente `Semaforo`. Si `semaforo` es `null` (Sprint 2), la sección **no aparece**.
- **Tarjetas** (`TarjetaSigno`): nombre, valor con su unidad y decimales, flecha (↑ "subiendo", ↓ "bajando", → "estable"; sin flecha si es `null`) y "hace N min".
- La PA se toma una vez al día: su tarjeta muestra la hora ("hoy 07:30", "ayer 07:30") en lugar de "hace N min", y el backend la da por reciente durante 24 h.
- Con `reciente = false`: en lugar del valor, "Sin datos recientes · última 13:42 UTC", en gris. **Nunca** se muestra un valor viejo como actual.
- Sin ningún dato (`null`): "Aún sin datos".
- Móvil: tarjetas en 2 columnas; escritorio: 4.

| Elemento | Especificación |
|---|---|
| Selector de periodo | Botones de opción "24 h" (agregados por hora, `series24h`) y "7 días" (por día, `series7d`). Se recuerda en `localStorage` |
| Tarjetas | Las 7 variables. La seleccionada tiene borde de acento y `aria-pressed="true"` |
| Gráfica (`GraficaSerie`) | Línea de la `media` con área sombreada entre `minimo` y `maximo`. Banda horizontal de la línea base (`media ± desviacion`) si existe. Franjas de **ejercicio** (`bloquesEjercicio`, solo en 24 h) con la leyenda "Ejercicio". La PA dibuja dos líneas (sistólica y diastólica) |
| Pie de la gráfica | "Media · Mín · Máx" del periodo, y "Línea base μ ± σ (<fuente>)" o "Sin línea base todavía" |
| Sin datos en el periodo | `EstadoVacio`: "Todavía no hay datos de <variable> en este periodo." |
| Refresco | `usePoll(10000, { only: ['ultimos', 'flechas', 'series24h'] })` |
| Sin conexión | Última copia de `instantaneas` (M15) con la marca "Datos de hace N min (sin conexión)" |

## Accesibilidad

- Cada tarjeta tiene `aria-label`: "Frecuencia cardiaca, 72 latidos por minuto, subiendo, medida hace 1 minuto". Sin juicio clínico.
- Cada gráfica tiene un resumen textual oculto visualmente: "Frecuencia cardiaca, últimas 24 horas: media 68, mínimo 58, máximo 152 lpm".

## Criterios de aceptación

- **Dado** una FC con `reciente = false` y última lectura a las 13:42, **cuando** se muestra la tarjeta, **entonces** dice "Sin datos recientes · última 13:42 UTC" y no muestra el valor.
- **Dado** `semaforo = null`, **cuando** se abre el inicio, **entonces** no aparece "Estado por sistema".
- **Dado** que pulso la tarjeta de SpO₂, **cuando** cambia la gráfica, **entonces** muestra la SpO₂ con su línea base si existe.
- **Dado** la FR, **cuando** se muestra, **entonces** su unidad es "rpm" (no "lpm").
- **Dado** "7 días", **cuando** recargo la página, **entonces** sigue elegido "7 días".
- **Dado** que no hay conexión, **cuando** abro la página, **entonces** veo la última copia con su marca de tiempo.
