## Especificación

**Migración `create_pruebas_ortostaticas`**

| Columna | Definición en Laravel | Notas |
|---|---|---|
| `id` | `$table->uuid('id')->primary();` | Generado en el cliente (idempotencia de la cola offline) |
| `tripulante_id` | `$table->uuid('tripulante_id');` | |
| `realizada_en` | `$table->dateTime('realizada_en', 3);` | |
| `modalidad` | `$table->string('modalidad', 6);` | `de_pie` o `lbnp` |
| `fc_basal`, `fc_estimulo` | `$table->unsignedSmallInteger(...);` | lpm |
| `pas_basal`, `pad_basal`, `pas_estimulo`, `pad_estimulo` | `$table->unsignedSmallInteger(...);` | mmHg |
| `caida_sistolica`, `caida_diastolica` | `$table->smallInteger(...);` | basal − estímulo (puede ser negativa si la presión **sube**) |
| `umbral_sistolica`, `umbral_diastolica` | `$table->unsignedSmallInteger(...);` | **Nuevas.** Valores de `PA_ORTO_SIS` y `PA_ORTO_DIA` (M16) vigentes al registrarla. Con ellos se calculó el resultado, y así se puede explicar aunque después el médico cambie el umbral |
| `resultado` | `$table->string('resultado', 10);` | `normal` o `positiva` |
| `registrada_por` | `$table->unsignedBigInteger('registrada_por');` | Usuario (CMO) |
| `created_at` | `$table->dateTime('created_at', 3);` | |

- **Índice:** `(tripulante_id, realizada_en)`.
- **Inmutable:** sin `updated_at`. Una corrección es una prueba nueva.

## Criterios de aceptación

- **Dado** una prueba con PAS basal 120 y con estímulo 125, **cuando** se guarda, **entonces** `caida_sistolica = -5`.
- **Dado** que reenvío la misma prueba (mismo `id`), **cuando** se guarda, **entonces** sigue habiendo una fila.
