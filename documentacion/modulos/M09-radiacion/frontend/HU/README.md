Trabajo de **Inertia + Vue 3 + Tailwind CSS v4** de M09: qué páginas hay, **cómo deben verse**, qué textos llevan y cómo se comportan. Lo hace **Gabriela**. Las *props* vienen de las [historias de backend](../../backend/HU/README.md).

## Reglas comunes

- Se siguen la [guía visual provisional](../../../M01-identidad/frontend/HU/README.md#guía-visual-provisional) y la [estructura común de las aplicaciones](../../../M01-identidad/frontend/HU/README.md#estructura-común-de-las-cuatro-aplicaciones) de M01. Textos para el astronauta **de tú**.
- **Unidades:** dosis en mSv con 1 decimal ("312,4 mSv"); tasa en mSv/d con 2 decimales ("0,51 mSv/d").
- **La alarma "IR AL REFUGIO" no es de M09:** la muestra `AlarmaCritica` de M13 (ventana modal con sonido) en todas las páginas de F1 y F2. M09 añade el **detalle** de la dosis del evento.
