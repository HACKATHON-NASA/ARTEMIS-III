# HU-00.03 · Librería de componentes Vue compartidos

> [← Fundaciones](README.md) · [Plan de sprints](../plan-de-sprints.md#3-sprint-0--fundaciones) · Anterior: [HU-00.01 · Repositorio](HU-00.01-repositorio-y-estructura-de-modulos.md)

**Como** equipo de desarrollo, **quiero** una librería de componentes Vue compartidos, **para** que las cuatro aplicaciones se vean coherentes y ningún módulo reinvente una tarjeta, un semáforo o una gráfica.

| Prioridad | Sprint | Depende de | Pts |
|---|:---:|---|:---:|
| Must | 0 | HU-00.01 | 5 |

La usan casi todas las historias de frontend. Las más urgentes son `EstadoVacio` y `Cargando`, que necesitan las páginas temporales de [HU-01.01](../../modulos/M01-identidad/frontend/HU/HU-01.01-inicio-de-sesion.md): se hacen **primero** y se fusionan aparte si el resto va más lento.

## Especificación

**1. Qué es y qué no es.**
- Son **6 componentes de dominio** que repiten los módulos. Botones, campos, diálogos, menús, tablas y pestañas **no** se crean: se usan los del *kit* (`components/ui`). Si falta alguno (por ejemplo `Table`, `Select`, `Tooltip`, `Tabs` o `Badge`), se añade con la herramienta del *kit* (shadcn-vue), igual que los que ya trae.
- Los componentes de un solo módulo (`IndicadorSincronizacion` de M15, `AlarmaCritica` de M13, `DiaMision` de M02, `TarjetaTripulante` de M04…) los hace cada módulo en su historia, **encima** de estos.
- Sigue la [guía visual provisional](../../modulos/M01-identidad/frontend/HU/README.md#guía-visual-provisional) y las [convenciones del frontend](../../modulos/README.md#convenciones-del-frontend).

**2. Tokens de diseño** en `resources/css/app.css` (bloque `@theme` de Tailwind v4), para cambiar la marca después en un solo lugar:

| Variable | Uso |
|---|---|
| `--color-acento` | Acción principal |
| `--color-critico` | Rojo: crítico, errores y acciones destructivas |
| `--color-aviso` | Amarillo: atención |
| `--color-normal` | Verde: normal |

Cada una con su variante para el tema oscuro y contraste AA sobre el fondo. Ningún componente escribe un color a mano (`bg-red-600`): usa estas variables.

**3. Tipos compartidos** en `resources/js/contratos/`:

```ts
// semaforo.ts — de M13 §3.6
export type Sistema = 'corazon' | 'sueno' | 'mente' | 'radiacion' | 'cuerpo' | 'ambiente'
export type Color = 'verde' | 'amarillo' | 'rojo'
export const SISTEMAS: Record<Sistema, string> = { corazon: 'Corazón', sueno: 'Sueño', mente: 'Mente',
  radiacion: 'Radiación', cuerpo: 'Cuerpo', ambiente: 'Ambiente' }
```

`roles.ts` (constante `ROLES`) lo crea HU-01.01 en la misma carpeta.

**4. Formato** (`resources/js/lib/formato.ts`), funciones puras con sus pruebas:

| Función | Ejemplo |
|---|---|
| `numero(valor, decimales)` | `36.75, 1` → `"36,8"` (`Intl.NumberFormat('es-CO')`) |
| `fechaUtc(iso, diaMision?)` | Con día de misión: `"D12 · 14:05 UTC"`; sin misión: `"2026-10-16 14:05 UTC"` |
| `haceCuanto(iso, ahora?)` | `"hace 3 min"`, `"hace 2 h"`, `"hace 4 días"`; `null` → `"Nunca"` |

El formato de cada variable (unidad y decimales por código LOINC) **no** va aquí: es de M04 y usa estas funciones.

**5. Componentes** (`resources/js/components/`, carpeta del *kit*):

| Componente | *Props* | Qué muestra |
|---|---|---|
| `EstadoVacio.vue` | `texto: string`, `titulo?: string`, `icono?` (Lucide) · *slot* `accion` | Icono, título opcional y texto centrados. El *slot* es para un botón o enlace ("Registrar noche", "Quitar filtros") |
| `Cargando.vue` | `texto?: string` (por defecto "Cargando…"), `variante?: 'linea' \| 'bloque'` | Indicador con `role="status"` y el texto visible para lectores de pantalla. `bloque` es un esqueleto del alto del contenido |
| `Semaforo.vue` | `estados: Partial<Record<Sistema, Color>>`, `compacto?: boolean` | Una fila con un elemento por sistema, en el orden de `SISTEMAS`: icono + texto (✔ "Normal", ⚠ "Atención", ✖ "Crítico") y el nombre del sistema. `compacto` (tarjetas de F2) deja solo el icono, con el texto en `aria-label` y `title`. El color **nunca** va solo |
| `TarjetaSigno.vue` | `nombre: string`, `valor: string \| null` (ya formateado), `unidad: string`, `tendencia: 'sube' \| 'baja' \| 'estable' \| null`, `medidoEn: string \| null`, `reciente: boolean`, `banda?: { min: string, max: string }` | Nombre, valor grande con su unidad, flecha (↑ "subiendo", ↓ "bajando", → "estable"; nada si es `null`) y "hace N min". Sin dato: "—" y "Sin datos". Con `reciente = false`, el valor se atenúa y añade "Dato antiguo". `aria-label` completo: "Frecuencia cardiaca, 72 latidos por minuto, subiendo, medida hace 1 minuto". **No** dice "normal" ni "anormal" |
| `InsigniaAlerta.vue` | `activas: number`, `nivelMaximo: 'aviso' \| 'critico' \| null` | Para el menú (`resumenAlertas` de M13). Con 0 no se muestra. Número + icono del nivel (⚠ o ✖); `aria-label` "3 alertas activas, la más grave crítica". Más de 99: "99+" |
| `GraficaSerie.vue` | Ver punto 6 | Gráfica de ECharts común a M04, M05, M07, M08, M09 y M10 |

**6. `GraficaSerie.vue`.** Un solo envoltorio de ECharts (`echarts` + `vue-echarts`, importando solo los módulos usados para no inflar el paquete). Los módulos le pasan datos ya preparados; **no** calcula nada clínico.

```ts
props: {
  series: { nombre: string, tipo: 'linea' | 'barras',
            puntos: { x: string | number, y: number | null, forma?: 'circulo' | 'triangulo' | 'cuadrado' | 'rombo',
                      hueco?: boolean, nota?: string }[],
            rango?: { x: string | number, min: number, max: number }[] }[],   // área sombreada mínimo–máximo
  ejeX: 'tiempo' | 'categoria',          // tiempo: ISO UTC; categoria: número de sesión, día…
  unidad: string,
  bandas?:  { desde: number, hasta: number, texto: string }[],                        // horizontales: línea base, rango de referencia
  lineas?:  { valor: number, texto: string, estilo: 'continua' | 'discontinua' | 'punteada' }[],  // umbrales y límites
  franjas?: { desde: string, hasta: string, texto: string }[],                        // verticales: ejercicio
  marcas?:  { x: string | number, texto: string }[],                                  // líneas verticales: "lanzamiento"
  tendencia?: { texto: string },          // recta de mínimos cuadrados sobre la primera serie, con su texto en la leyenda
  alto?: number,                          // px, por defecto 280
  resumen: string,                        // texto para lectores de pantalla
}
```

Cubre todos los usos de las fichas: banda de línea base y área mínimo–máximo (M04), eje por número de sesión con marcadores huecos (M05), rango de referencia, límites críticos, forma por interpretación y tendencia (M07), líneas de pCO₂ y límites con fuente (M08), barras por día con nota (M09) y líneas de glucosa (M10).

| Regla | Detalle |
|---|---|
| Fechas | El eje de tiempo se rotula en UTC con `fechaUtc` |
| `y = null` | Hueco en la línea (no se une a través de los datos que faltan) |
| Tema | Lee los colores de las variables CSS y se actualiza al cambiar a modo oscuro |
| Tamaño | Ocupa el ancho del contenedor y se redibuja al cambiar el tamaño |
| Accesibilidad | `role="img"` con `aria-label = resumen`, y debajo un botón "Ver datos en tabla" que muestra los puntos en una tabla accesible |
| Sin puntos | Muestra `EstadoVacio` con "Todavía no hay datos de esta variable." |

**7. Catálogo de desarrollo.** Página `Dev/Componentes`, en la ruta `/dev/componentes`, que **solo existe con `APP_ENV=local`**. Muestra cada componente en todos sus estados con datos de ejemplo. Así cada módulo ve qué hay antes de crear algo propio, y se revisa el modo oscuro y el móvil de una vez.

## Criterios de aceptación

- **Dado** `Semaforo` con `{ corazon: 'rojo', sueno: 'verde' }`, **cuando** se muestra, **entonces** se lee "Corazón Crítico" y "Sueño Normal", con icono además del color.
- **Dado** `TarjetaSigno` sin valor, **cuando** se muestra, **entonces** se ve "—" y "Sin datos", sin flecha.
- **Dado** `InsigniaAlerta` con `activas = 0`, **cuando** se muestra el menú, **entonces** no aparece; con `150`, se lee "99+".
- **Dado** `GraficaSerie` con una banda, dos líneas de umbral y un punto `null`, **cuando** se dibuja, **entonces** la línea se corta en el hueco y la leyenda muestra los textos de las líneas.
- **Dado** `GraficaSerie`, **cuando** pulso "Ver datos en tabla", **entonces** aparece una tabla con encabezados `<th scope="col">` y los mismos valores.
- **Dado** el modo oscuro, **cuando** abro `/dev/componentes`, **entonces** todos los componentes conservan contraste AA.
- **Dado** `APP_ENV=production`, **cuando** abro `/dev/componentes`, **entonces** recibo `404`.
- **Dado** una pantalla de 375 px, **cuando** abro `/dev/componentes`, **entonces** no hay desplazamiento horizontal.
