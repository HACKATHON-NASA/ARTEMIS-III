# resources/js/types · Tipos globales

Tipos de las *props* **compartidas** de Inertia (`auth`, `nodo`, `mision`, `flash`…, de `HandleInertiaRequests`) y los del *kit*. Los tipos de las páginas de un módulo van en `modules/<Modulo>/Types/`.

> 📝 **Documentar siempre:** si cambia lo que hace esta carpeta o añade un tipo de archivo nuevo, actualice este README y el CHANGELOG en el mismo *pull request*.
