# resources/js/pages · Páginas globales

Páginas que **no son de ningún módulo**: las de error (`Errores/Error.vue`, HU-00.01) y el catálogo de componentes (`Dev/Componentes.vue`, solo en local, HU-00.03).

Hoy contiene las páginas del *starter kit* (`auth/`, `settings/`, `Dashboard`, `Welcome`). En HU-00.01 y HU-01.01 pasan a `modules/Identidad/Pages/` y se configura el resolver de Inertia para buscar en `modules/*/Pages/`.

> 📝 **Documentar siempre:** si cambia lo que hace esta carpeta o añade un tipo de archivo nuevo, actualice este README y el CHANGELOG en el mismo *pull request*.
