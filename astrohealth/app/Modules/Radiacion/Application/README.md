# Application (= Service: casos de uso) · M09 Radiación

> `astrohealth/app/Modules/Radiacion/Application/` · [Ficha de backend de M09](../../../../../documentacion/modulos/M09-radiacion/backend/README.md) · [Norma](../../../../../documentacion/modulos/00-arquitectura/ARCHITECTURE.md#9-reglas-de-service)

Los **casos de uso**: una clase por acción (`<Verbo><Cosa>`), con un único método público `ejecutar()`. Coordina repositorios, reglas del dominio, contratos de otros módulos, la transacción y los eventos.

| Va aquí | No va aquí |
|---|---|
| Servicios como `RegistrarSintoma`; la subcarpeta `DTOs`. | SQL, `DB::`, Query Builder, `Request`, respuestas HTTP o páginas. |

**Archivos previstos para M09 en esta carpeta:** los lista la ficha, en [§6 Archivos](../../../../../documentacion/modulos/M09-radiacion/backend/README.md#6-archivos).
